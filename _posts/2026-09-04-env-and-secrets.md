수업에서 `.env` 라는 파일 얘기가 나왔다.
내 컴퓨터에도 있는지 찾아봤는데 **없었다.** 그러다 걱정이 됐다.

> 그럼 내 비밀번호 같은 건 다 공개되어 있는 건가?

## 먼저, `.env` 가 없다는 건 무슨 뜻인가

**비밀번호를 담아둘 파일을 아직 만든 적이 없다**는 뜻이다.
비밀번호가 어딘가 공개돼 있다는 뜻이 아니다.

`.env` 는 나중에 API 키 같은 걸 쓰는 프로그램을 만들 때 필요해지는 파일이다.
아직 그런 프로그램을 만든 적이 없으니 없는 게 정상이다.

공개되어 있는 건 GitHub 공개 저장소에 올린 파일뿐이다.
저장소 네 개를 검색해봤더니 비밀번호나 열쇠가 올라간 건 없었다.

지금 내 비밀번호 종류는 이렇게 있다.

| 무엇 | 어디에 | 공개 여부 |
|---|---|---|
| GitHub 로그인 비밀번호 | GitHub 서버 + 브라우저 저장 | 비공개 |
| SSH 개인키 | 내 컴퓨터 `.ssh` 폴더 | 내 컴퓨터에만. 저장소엔 없음 |

## SSH 개인키는 `.env` 에 넣는 게 아니다

헷갈렸던 부분이다.

- **SSH 개인키** — 파일 그 자체로 `.ssh` 폴더에 둔다. `ssh` 가 그 경로에서 읽어간다. 옮겨 적지 않는다
- **`.env`** — `이름=값` 목록이다. API 키나 DB 비밀번호처럼 **짧은 문자열**을 넣는다

개인키처럼 여러 줄짜리 파일은 `.env` 에 넣지 않는 게 보통이다.

## 환경변수라는 말이 안 와닿았다

몇 번을 들어도 감이 안 왔다. 말을 쪼개보니 정리가 됐다.

- **변수** = 이름이 붙은 값
- **환경** = 그 프로그램이 실행되고 있는 바깥 상황. 어느 컴퓨터에서, 누구 계정으로, 어떤 서버에서 돌고 있는지

그래서 **환경변수는 프로그램 바깥에 놓여 있는, 이름이 붙은 값**이다.
코드 안에 적혀 있는 게 아니라, 프로그램이 실행될 때 바깥에서 가져다 쓴다.

이름이 "환경"인 이유가 여기 있다.
**코드는 똑같은데, 어디서 실행되느냐에 따라 값이 달라진다.**

같은 프로그램이 `API_KEY` 를 달라고 하면

- 내 컴퓨터에서 돌 때 → 내 컴퓨터에 놓인 값
- 서버에서 돌 때 → 서버에 놓인 값

값이 코드에 속하지 않고 **실행되는 환경에 속해 있는** 것이다.

## 나쁜 예 / 좋은 예

**나쁜 예** — 코드에 그대로 박아 넣기

```
apiKey = "sk-a1b2c3d4e5f6..."
```

이대로 GitHub에 올라가면 순식간에 유출된다.

**좋은 예** — 코드는 '불러오기'만

```
apiKey = 환경변수에서 불러오기
```

실제 값은 코드 밖 `.env` 파일에 두고, 그 파일은 `.gitignore` 로 깃에 안 올라가게 막는다.

## 배포할 때 가장 많이 나는 사고

수업에서 들은 것 중 이게 제일 와닿았다.

1. 내 컴퓨터에서는 프로그램이 `.env` 에서 값을 읽어서 잘 돈다
2. `.env` 는 GitHub에 **일부러 안 올린다.** 공개되면 유출이니까
3. 그런데 배포는 GitHub에 올라간 것으로 이뤄진다 → **서버에는 그 값이 없다**
4. 그래서 배포 플랫폼 설정 화면에 같은 값을 손으로 넣어줘야 한다

4번을 빼먹으면 코드는 똑같은데 서버에서만 값이 비어 있다.
그래서 **"내 컴퓨터에선 되는데 배포하면 안 되는"** 상태가 된다.

원인을 모르면 코드를 계속 들여다보게 되는데, 코드에는 문제가 없다.

## 곁가지 - 도메인 파는 곳과 사이트 만들어주는 곳

수업에서 업체 이름이 여럿 나와서 정리했다.

| | 하는 일 |
|---|---|

주소를 파는 쪽과 그 주소로 열리는 사이트를 만들어주는 쪽의 차이다.
다만 카페24는 도메인 판매와 호스팅도 같이 한다.

**"쇼핑몰 특화"는 아임웹보다 카페24 쪽 성격이다.**
아임웹은 홈페이지·포트폴리오·예약 같은 일반 웹사이트가 중심이고 쇼핑몰 기능도 함께 제공한다.

## 정리

- `.env` 가 없다는 건 비밀값을 쓰는 프로그램을 아직 안 만들었다는 뜻이다
- SSH 개인키는 `.env` 가 아니라 `.ssh` 폴더에 파일로 둔다
- 환경변수 = 코드 바깥에 놓인, 이름 붙은 값. **어디서 실행되느냐에 따라 값이 달라진다**
- 배포할 때 그 값을 플랫폼 설정에 따로 넣어주지 않으면 서버에서만 동작하지 않는다
