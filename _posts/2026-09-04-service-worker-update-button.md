> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

블로그를 새로 배포하면 방문자 화면에 `New content available` 알림과 `Update` 버튼이 뜬다.
전날엔 이 버튼을 누르니 바로 새로고침되면서 새 글이 보였다.

그런데 다음 날엔 **눌러도 아무것도 안 바뀌었다.**
주소창에서 엔터를 치니 그제야 새 글이 나왔다.

같은 버튼인데 왜 다른가. 코드를 열어봤다.

## `Update` 버튼이 실제로 하는 일

```javascript
r.addEventListener("click", () => {
  e.waiting && e.waiting.postMessage("SKIP_WAITING");  // 대기 중인 워커에 교체 신호
  o.hide();                                            // 알림 닫기
});
```

두 가지뿐이다. **버튼 자체는 새로고침을 하지 않는다.**

## 새로고침은 다른 데 붙어 있다

```javascript
navigator.serviceWorker.addEventListener("controllerchange", () => {
  window.location.reload();
});
```

`controllerchange` — **이 페이지를 맡고 있는 워커가 실제로 바뀌었을 때** 일어나는 일이다.
새로고침은 여기에 붙어 있다.

정리하면 이렇다.

| 순서 | 무슨 일 |
|---|---|
| 1 | 버튼을 누른다 → 대기 중인 워커에게 "네가 맡아라" 신호 |
| 2 | 교체가 실제로 일어난다 |
| 3 | **그 결과로** `controllerchange` → 새로고침 |

**2번이 안 일어나면 3번도 없다.** 알림만 닫히고 화면은 그대로다.

## 그럼 2번이 왜 안 일어나나

Chirpy의 `sw.min.js` 를 보니 **`clients.claim()` 이 없다.**

이게 없으면 새 워커가 활성화돼도 **이미 열려 있던 페이지를 자기 관할로 가져오지 않는다.**
다음에 그 페이지를 새로 열 때부터 맡는다.

그래서 이런 상황이 생긴다.

> 페이지를 열었을 때 **그 페이지를 맡고 있는 워커가 아예 없었다면**,
> 새 워커가 활성화돼도 이 페이지를 넘겨받지 않는다.
> → `controllerchange` 가 없다 → 새로고침도 없다.
{: .prompt-warning }

## 어제와 오늘의 차이

| | 페이지를 열 때 상태 | 결과 |
|---|---|---|
| 전날 | 워커가 며칠 전부터 그 페이지를 맡고 있었음 | 교체 → `controllerchange` → **새로고침 O** |
| 이날 | **전날 밤 설정을 되돌리면서 워커가 새로 등록됨** | 맡은 관할이 없음 → **새로고침 X** |

전날 밤에 PWA 캐시 설정을 되돌린 일이 있었다. 그때 워커가 새로 등록됐다.
어제와 오늘 사이에 실제로 그런 일이 있었으니 이 설명이 가장 맞아 보인다.

다만 **브라우저 안에서 실제로 그랬는지까지 확인한 것은 아니다.**
코드로 확인한 것은 "교체가 일어나야만 새로고침된다"는 조건까지다.

## 워커의 상태 이름

이 얘기를 하면서 헷갈렸던 부분이다.

```
installing  →  waiting  →  activated
```

`waiting`(대기)은 **새 워커가 잠깐 거쳐가는 상태 이름**이다.
"대기 중인 워커가 없다"는 말은 새 내용이 없다는 뜻이 아니라,
**이미 `activated` 로 넘어갔다**는 뜻이다.

주소창에서 엔터를 쳤을 때 새 화면이 나온 것이 그 증거다.
새 워커는 있었고, 활성 상태였고, 다만 **이미 열려 있던 그 페이지를 맡고 있지 않았을 뿐**이다.

## 다음에 확인할 것

이제 워커가 등록돼 있으니, 앞으로 여는 페이지는 워커가 맡은 상태로 열린다.
그러면 `Update` → 교체 → 새로고침이 이어질 것이다.

**이건 코드에서 나온 예측이고, 다음에 글을 올려봐야 확인된다.**

## 정리

- `Update` 버튼은 교체 신호를 보내고 알림을 닫을 뿐이다
- 새로고침은 `controllerchange`(관할 워커가 실제로 바뀜)에 붙어 있다
- `clients.claim()` 이 없으면 새 워커는 **이미 열려 있던 페이지를 넘겨받지 않는다**
- 그래서 "버튼을 눌렀는데 아무 일도 안 일어나는" 경우가 생긴다
