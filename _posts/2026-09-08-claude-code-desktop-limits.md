> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

개념을 배우다가 실제 파일과 명령을 찾아보게 됐다.
그런데 수업에서 본 것과 내 화면이 다른 게 몇 개 있었다. 원인은 대체로 **창이 다르기 때문**이었다.

## 설정 파일이 실제로 어디 있나

**작업 폴더에 `.claude` 폴더가 없었다.**

찾아보니 없는 게 맞았다. `.claude` 는 **그 폴더에서만 쓸 설정이나 스킬을 넣을 때** 생긴다.
안 만들면 없다.

**`C:\Users\ctale\.claude` 에도 `skills` 폴더가 없었다.**

이건 **직접 만든 스킬이 아직 없다는 뜻**이었다.
엑셀·PDF·코드검사 같은 스킬들은 클로드 코드에 딸려 온 것이라 이 폴더에 파일로 있지 않다.

**`CLAUDE.md` 위치**

내 것은 작업 폴더 루트에 있었다.

```
C:\Users\ctale\Desktop\claudecode\CLAUDE.md
```

수업에서는 `.claude` 밑에 있다고 했는데, **둘 다 맞다.** 자리가 한 군데가 아니다.
루트에 둬도 읽히고 `.claude` 안에 둬도 읽힌다.

## 파워셸에서 `claude` 를 쳐도 아무 일도 안 일어난다

찾아보니 PATH에도 없고 흔한 설치 자리에도 없었다. **안 깔려 있었던 것이다.**

내가 쓰는 것은 **데스크톱 앱**이고, 파워셸의 `claude` 는 **터미널용 클로드 코드**를 부르는 명령이다.
둘은 별개로 설치한다. 같은 클로드 코드인데 창이 두 종류라서, 앱만 깔면 터미널 명령은 생기지 않는다.

## `/plugin` 이 안 된다

플러그인을 설치해 보려고 이렇게 쳤다.

```
/plugin marketplace add anthropics/claude-plugins-community
/plugin install <플러그인이름>@claude-community
```

돌아온 답은 `/plugin isn't available in this environment` 였다.

이유는 앞서 배운 것과 같은 구조였다.
**이 창의 몸(하네스)에 그 손이 안 붙어 있어서**다.
머리가 "설치해야지" 해도 손이 없으면 못 한다. 터미널 창의 몸에는 그 손이 붙어 있어서 거기서는 된다.

대신 해줄 도구도 없었다. 클로드가 가진 플러그인 도구는 회사 카탈로그만 뒤지고,
GitHub 주소로 마켓플레이스를 추가하는 기능이 없다.

`/permissions`·`/config`·`/hooks` 같은 명령도 이 창에서는 안 된다.

## `plugin marketplace add anthropics/claude-plugins-community` 는 무슨 뜻인가

명령이 무슨 말인지 몰라서 뜯어봤다.

- `/plugin` — 플러그인 관련 명령이라는 뜻
- `marketplace add` — 플러그인 모음집 하나를 **등록**해라
- `anthropics/claude-plugins-community` — 어느 모음집인지

마지막은 `계정이름/저장소이름` 형식이다. 내 것으로 치면 `ctaleez51-art/PROJECT` 같은 꼴이고,
풀어 쓰면 `https://github.com/anthropics/claude-plugins-community` 다.

전체 뜻은 **"이 GitHub 저장소를 플러그인 모음집으로 등록해라"** 다.
등록만 하는 것이고, 실제로 설치하는 건 다음 줄의 `install` 이다.

여기서 한참 헷갈렸다. 내가 쓰려는 건데 왜 주소를 등록하나 싶었다.
등록하는 주체가 내가 아니라 **클로드**여서였다. 클로드가 그 주소를 적어둬야
다음 줄에서 이름만 대도 어디서 가져올지 안다.

## 젠스파크와 oh-my-openagent

자료에 나온 `oh-my-openagent` 가 젠스파크 같은 서비스인지 물었다.
결은 비슷했다. 둘 다 여러 모델을 골라 부려서 일 시키는 쪽이다.

차이는 **완성품이냐 아니냐**다.
젠스파크는 가입하면 바로 쓰는 서비스고, `oh-my-openagent` 는 직접 깔아서 설정해야 하는 도구다.

## 노션에 붙여넣기 — 마크다운으로 주면 된다

수업 자료를 노션에 정리하려고 했다.
노션은 **마크다운을 붙여넣으면** 제목·목록·표·코드블록으로 알아서 바뀐다.
그래서 문장은 손대지 않고 구조만 잡아주면 됐다.

- 표는 **마크다운 표 형식**으로 다시 짜야 붙는다. 열이 붙어버린 원문은 못 알아본다
- 끊겨 있는 명령줄은 코드블록으로 다시 묶어야 한다
- 노션에서 점(불릿)은 `-` 또는 `*` 를 치고 스페이스바를 누르면 붙는다. 백스페이스로 취소된다

## 정리

창이 다르면 되는 게 다르다. 이게 이날 확인한 것 중 제일 실용적인 부분이었다.

| | 데스크톱 앱 | 터미널 CLI |
|---|---|---|
| 대화·파일 작업 | 된다 | 된다 |
| `/plugin` | **안 된다** | 된다 |
| `/permissions`·`/config`·`/hooks` | **안 된다** | 된다 |

그리고 설치는 **별개**다. 앱을 깔았다고 터미널 명령이 생기지 않는다.
