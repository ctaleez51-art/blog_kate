> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

앞 글에서 에이전트는 머리(LLM) + 몸(하네스)이고, LLM은 판단만 한다고 정리했다.
그러면 나머지는 다 하네스가 하는 걸까. 그게 궁금해서 더 물었다.

## 구분 기준은 하나 — 똑똑함이 필요한가

- 필요하다 → 모델에게 넘긴다
- 필요 없다 → 하네스가 직접 한다

**규칙으로 정해지는 일, 즉 판단이 필요 없는 일**을 하네스가 직접 한다.

## 하네스가 직접 하는 것

- **도구 실행** — 파일을 읽고 쓰고, 명령을 실행하고, 네트워크에 요청을 보낸다.
  실제로 컴퓨터를 만지는 것은 전부 하네스다
- **보낼 내용 조립** — 매 호출마다 지시문·대화 기록·도구 목록을 붙여 LLM에게 보낸다.
  LLM은 기억이 없으므로 매번 새로 조립해야 한다
- **답 해석(파싱)** — LLM이 내놓은 텍스트에서 "도구 호출" 부분을 뽑아낸다. 형식이 틀리면 걸러낸다
- **권한 확인** — 사용자에게 물어보고, 허락이 없으면 실행하지 않는다.
  규칙으로 막아둔 것은 LLM이 하자고 해도 안 된다
- **루프 제어** — 다시 호출할지 멈출지, 몇 번까지 돌지
- **화면 표시와 입력 받기**
- **오류 처리·재시도, 사용량 집계**

## "실행중"이 떠 있는 동안 벌어지는 일

채팅창에 뭔가를 입력하면 `실행중 >` 같은 표시가 뜨고, 나중에 `>` 를 펼치면
무엇을 했는지가 적혀 있다. 이게 하네스가 일하는 화면인지 물었다.

화면을 띄우는 것은 하네스가 맞다. 다만 그 동안 벌어지는 일은 하네스만의 일이 아니었다.

```
[실행중 ─────────────────────────────────]
   ↑모델 호출  ↑도구 실행  ↑모델 호출  ↑도구 실행 ...
   (기다림)    (하네스)    (기다림)    (하네스)
```

- **모델 호출 구간** — 하네스가 LLM에게 물어보고 답을 기다리는 시간.
  하네스는 놀고 있고 모델이 판단하는 중이다
- **도구 실행 구간** — 하네스가 실제로 파일을 읽거나 명령을 실행하는 시간

`>` 를 펼쳐서 나오는 내용은 하네스가 남긴 **기록**이다.
어떤 도구를 어떤 값으로 호출했고 결과가 무엇이었는지를 하네스가 적어둔 것.

그리고 모델은 그 화면을 보지 못한다. "실행중"이라는 글자도, `>` 가 접혀 있는지 펼쳐져 있는지도
모델에게는 가지 않는다. 화면은 전부 하네스와 사용자 사이의 일이다.

## 그림과 영상은 LLM이 만드는 게 아니다

LLM이 그림도 그리고 영상도 만드는데, 그러면 그건 하네스가 하는 일인가 하고 물었다.
답은 둘 다 아니었다.

**그림과 영상은 LLM이 아닌 별개의 모델이 만든다.**

- **LLM** — 텍스트 모델. 텍스트만 내놓는다. 그림을 못 그린다
- **이미지 생성 모델 / 영상 생성 모델** — 각각 따로 있는 모델이다. LLM이 아니다

그림이 나오는 순서는 이렇다.

1. 사용자가 "고양이 그려줘"라고 한다
2. 하네스가 그 말을 LLM에게 준다
3. LLM이 "이미지 모델을 이런 프롬프트로 호출해라"라는 **텍스트**를 답으로 내놓는다
4. 하네스가 이미지 생성 모델을 호출한다
5. 이미지 모델이 그림을 만들어 돌려준다

하네스는 3번의 요청을 받아 5번의 모델에게 심부름을 간 것이다. 그리는 일 자체는 하지 않는다.
하네스에게 이미지 생성 모델은 **도구 하나**다. 파일 읽기 도구와 같은 자리에 있다.

그러니까 "LLM은 판단만 하고 나머지는 다 하네스"는 거친 말이었다.
정확히는 **하네스가 직접 하는 일도 있고, 다른 모델에게 넘기는 일도 있다.**

## 루프를 많이 돌면 좋은가

에이전트는 루프를 돈다고 했으니, 많이 돌면 좋은 건지 물었다. 아니었다.

- 한 바퀴 돌 때마다 모델에게 물어보는 것이라 시간도 돈도 든다. 열 바퀴 돌면 열 번 값을 낸다
- 돌 때마다 대화가 길어진다. 길어지면 앞에 뭘 했는지 헷갈리기 시작한다
- 답이 이미 나왔는데도 계속 돌면 괜히 고치다가 망치기도 한다

필요한 만큼만 도는 게 좋다는 것.
