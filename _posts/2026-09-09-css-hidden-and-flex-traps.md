화면 쪽에서 걸린 것들을 모아둔다. 하나같이 코드는 맞아 보이는데 화면이 딴판이었다.

## `[hidden]` 이 CSS에 덮여 있었다

"로그아웃했다 다시 로그인하면 이전 결과가 그대로 뜬다"는 증상이 있었다.
코드에서는 분명히 숨기고 있었다.

```js
result.hidden = true
```

이게 왜 안 먹는지 한참 못 찾았다.

원인은 **CSS 우선순위**였다.
`#result` 에 `card` 클래스가 붙어 있고, 내 CSS가 이렇게 지정한다.

```css
.card { display: flex; }
```

브라우저는 `hidden` 이 붙은 요소를 기본 스타일시트에서 `display: none` 으로 숨긴다.
그런데 **내가 쓴 CSS가 브라우저 기본을 덮어쓴다.**
그래서 `hidden` 을 걸어도 `display: flex` 가 이겨서 그대로 보였다.

```css
[hidden] { display: none !important; }
```

이 한 줄로 끝났다. 처음부터 이걸 안 넣은 게 문제였다.

`hidden` 은 속성이지 마법이 아니었다. 결국 `display` 하나를 두고 다투는 문제였다.

## 증상만 덮었더니 다른 데가 터졌다

원인을 찾기 전에는 다른 방법으로 덮었다.
화면을 다시 그리는 `render()` 안에서 결과 칸을 비우게 한 것이다.

증상은 사라졌는데, 새 문제가 생겼다.
**탭을 떠났다 돌아오면 해석이 사라졌다.**

`onAuthStateChange` 가 토큰 자동 갱신 때도 불리기 때문이었다.
로그인/로그아웃 때만 불리는 줄 알았는데 아니었다.

그래서 이렇게 바꿨다.

- `TOKEN_REFRESHED` / `USER_UPDATED` 는 건너뛴다
- 결과 칸을 비우는 것은 **로그아웃할 때만**

진짜 원인은 `[hidden]` 이 덮인 것이었고, 그걸 찾고 나서는 한 줄로 끝났다.
원인을 모르는 채로 증상을 덮으면 덮은 자리에서 새 문제가 나온다는 걸 이때 배웠다.

## flex 안에서 이미지가 세로로 늘어났다

카드 그림이 찌그러졌다. 해석 글이 길어지면 더 늘어났다.

```css
img { width: 150px; }
```

너비만 주고 높이를 안 줬는데, flex의 기본 동작이 항목을 세로로 늘린다(`align-items: stretch`).
옆에 있는 글이 길어질수록 그 높이에 맞춰 이미지도 같이 늘어난 것이다.

높이를 고정하고, 비율이 안 깨지게 하고, 늘어나지 않게 했다.

```css
img {
  width: 150px;
  height: 260px;
  object-fit: contain;
  align-self: flex-start;
}
```

## 줄바꿈이 무시됐다

AI 해석은 여러 단락으로 온다.
그런데 `textContent` 로 넣으면 줄바꿈이 무시돼서 한 덩어리로 붙어버린다.

```css
white-space: pre-wrap;
```

이걸로 해결했다.

`textContent` 를 쓰는 이유는 따로 있다.
AI가 쓴 글과 사용자가 쓴 질문을 `innerHTML` 로 넣으면 글 안의 태그가 실행될 수 있다.
그래서 `textContent` 는 유지하고 CSS로 푼 것이다.

## 방금 뽑은 것이 두 번 보였다

위쪽 결과 칸에 띄우고, 아래 "지난 기록" 목록에도 같은 게 나왔다.

DB에 넣을 때 방금 만든 줄의 id를 같이 받아오게 했다.

```js
.select("id").single()
```

그 id 하나만 목록에서 빼면 된다.
삭제하거나 다시 불러올 때도 유지되도록 변수(`shownResultId`)로 기억시켰다.

## 파일을 고쳤는데 화면이 그대로다

`styles.css` 와 `script.js` 를 고쳤는데 화면이 안 바뀌는 일이 반복됐다.
브라우저가 한 번 받은 파일을 기억해 두고 다시 안 받는다.

그냥 새로고침으로는 안 되고 **Ctrl + Shift + R**(캐시 무시)를 눌러야 한다.

이걸 모르면 "고쳤는데 안 고쳐졌다"고 착각해서 멀쩡한 코드를 계속 고치게 된다.
실제로 그렇게 여러 번 되돌아갔다.

시연 녹화 때는 문제가 안 된다. 녹화 중에 코드를 고치지 않으니까.
시크릿 창(Ctrl + Shift + N)으로 녹화하면 캐시도 비어 있고
저장된 비밀번호도 안 채워져서 깨끗하게 나온다.
