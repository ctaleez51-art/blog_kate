명령어를 받아서 파워셸에 붙여넣으면 실패하는 일이 계속 있었다.
명령어가 틀린 게 아니라 **창이 달랐다.**

## 원인 — 창이 두 종류다

윈도우에서 git을 쓰면 명령어를 칠 수 있는 창이 두 개 생긴다.

- **파워셸** — 윈도우 기본 창
- **Git Bash** — git을 설치하면 같이 깔리는 창. 리눅스 문법을 쓴다

두 창은 문법이 다르다. 리눅스 쪽 예제를 그대로 파워셸에 넣으면 안 된다.

## 실제로 부딪힌 것들

### `&&` 가 안 된다

```
'&&' 토큰은 이 버전에서 올바른 문 구분 기호가 아닙니다.
```

Windows PowerShell 5.1은 `&&` 를 못 쓴다. 명령을 이어 붙이는 구분자는 `;` 다.

```powershell
cd "저장소 경로"; git push
```

### `curl` 이 curl이 아니다

파워셸에서 `curl` 은 **다른 명령의 별칭**이다. 그래서 `curl -s` 같은 옵션을 못 받는다.
진짜 curl을 쓰려면 확장자를 붙인다.

```powershell
curl.exe -s "주소"
```

### `grep` 이 없다

파워셸에는 `grep` 이 아예 없다. 같은 일을 하는 것은 `Select-String` 이다.

```powershell
curl.exe -s "주소" | Select-String '"(state|merged)"'
```

## 한 장으로

| 하는 일 | Git Bash | 파워셸 |
|---|---|---|
| 명령 잇기 | `&&` | `;` |
| 웹 호출 | `curl -s` | `curl.exe -s` |
| 글자 찾기 | `grep -E` | `Select-String` |

## Git Bash 창은 `Ctrl+V` 가 안 먹는다

Git Bash는 mintty라는 별도 터미널이라 윈도우 기본 단축키가 그대로 통하지 않는다.

- **붙여넣기** — 창 안에서 마우스 우클릭, 또는 `Shift+Insert`
- **복사** — 드래그로 선택한 뒤 `Ctrl+Insert`

## 명령어는 `cd` 를 붙여서 받는다

`git push` 만 받아서 아무 창에나 치면, 다른 폴더에 있을 때 오류가 난다.
git 명령은 **그 저장소 폴더 안에서** 쳐야 한다.

```powershell
cd "C:\경로\저장소이름"; git push
```

앞에 `cd` 가 붙어 있으면 어디에 있든 그 자리로 옮겨간 뒤 실행된다.

## 결론

**굳이 Git Bash를 쓸 필요는 없다.** 파워셸에서 git 명령이 다 된다.
창을 하나로 정해두면 문법이 섞이는 일 자체가 없어진다.
