> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

숫자로 바꾼 데이터가 들어가는 곳이 **층(layer)** 이다.
층 안에서 무슨 일이 일어나는지가 어려울 줄 알았는데, **세 박자**뿐이었다.

## 은닉층이 왜 "숨은" 층인가

이름부터 걸렸다. 입력과 출력 사이에 낀 층들을 **은닉층(hidden layer)** 이라고 부른다.

숨겨놓았다는 뜻이 아니었다.
**우리가 직접 들여다보는 값이 아니라서** 그렇게 부른다.
입력은 내가 넣은 것이고 출력은 내가 받는 것인데, 그 사이 값은 모델이 속으로만 굴리는 계산이다.

## 한 층이 하는 일 = 세 박자

### 1. 곱하기 — 가중치 `W`

"이 입력은 얼마나 중요한가"를 반영한다.
중요하면 큰 수를 곱하고, 안 중요하면 작은 수를 곱한다.
**학습하면서 계속 바뀌는 값이 이것이다.**

### 2. 더하기 — 편향 `b`

저울의 영점을 맞추듯 결과를 위아래로 밀어 준다.
곱하기만으로는 원점을 지나는 선밖에 못 그리는데, 이걸 더해야 자리를 옮길 수 있다.

여기까지를 식으로 쓰면 이렇다.

```
Wx + b
```

**그게 전부다.** 곱하고 더한다.

### 3. 비틀기 — 활성화 함수

곱하고 더하기만 계속하면 아무리 층을 쌓아도 결국 **직선 하나**다.
층을 쌓는 의미가 없어진다. 그래서 사이에 한 번 비틀어 준다.

## ReLU — 하는 일이 허무할 만큼 단순하다

가장 많이 쓰이는 활성화 함수다.

> **음수가 나오면 0으로 눌러 버리고, 양수는 그대로 통과시킨다.**
{: .prompt-tip }

이게 전부다.

```
-3  →  0
-1  →  0
 0  →  0
 2  →  2
 5  →  5
```

이 작은 꺾임 하나가, 밋밋한 직선들의 합을 **곡선까지 그릴 줄 아는 모델**로 바꿔 놓는다.
직선을 아무리 더해도 직선이지만, 중간에 꺾어주면 여러 개를 이어 붙여 곡선 모양을 낼 수 있다.

## 그리고 반복된다

한 층에서 나온 결과가 **다음 층의 입력**이 된다.
거기서 또 곱하고, 더하고, 비튼다. 그 흐름이 출력까지 이어진다.

층을 깊게 쌓는다는 말은 이 세 박자를 여러 번 반복한다는 뜻이었다.

## 정리

- 은닉층 = 입력·출력 사이의 층. 내가 안 보는 값이라 "숨은"이다
- 한 층 = **곱하기(W) → 더하기(b) → 비틀기(활성화 함수)**
- 학습으로 바뀌는 것은 `W` 와 `b`
- 비틀기가 없으면 층을 쌓아도 직선 하나다
- ReLU = 음수는 0, 양수는 그대로. 이 꺾임이 곡선을 만든다
