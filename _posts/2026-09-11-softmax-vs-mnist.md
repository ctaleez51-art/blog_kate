> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

"softmax와 MNIST를 비교해달라"고 물었다가 질문 자체가 잘못됐다는 걸 알았다.
**둘은 같은 층위의 것이 아니다.**

## 한눈에

| | softmax | MNIST |
|---|---|---|
| 정체 | **함수** (수식) | **데이터셋** (파일) |
| 하는 일 | 점수를 확률로 바꾼다 | 학습·평가할 재료를 준다 |
| 크기·형태 | 벡터를 받아 같은 길이 벡터로. 합이 1 | 28×28 흑백 이미지 7만 장 + 정답 0~9 |
| 어디에 있나 | 모델의 **마지막 층** | 모델 **바깥**. 입력으로 들어감 |
| 바꾸면 | 출력을 해석하는 방식이 바뀜 | **푸는 문제 자체**가 바뀜 |
| 학습되나 | 아니오. 파라미터가 없다 | 아니오. 고정된 데이터 |

## MNIST는 문제, softmax는 답을 내놓는 방식

한 문장으로 정리하면 이렇다.

> **MNIST는 문제, softmax는 답을 내놓는 방식.**
{: .prompt-tip }

순서로 보면 이렇게 이어진다.

1. MNIST의 손글씨 이미지 한 장이 모델에 들어간다
2. 모델이 0부터 9까지 **10개의 점수**를 뱉는다
3. softmax가 그 점수를 **"3일 확률 92%"** 같은 형태로 바꾼다

## 바꿔 끼우면 무엇이 달라지나

이 부분이 둘의 차이를 가장 잘 보여줬다.

- **softmax를 다른 것으로 바꾸면** — 예를 들어 sigmoid로 바꾸면, 답을 해석하는 방식이 달라진다.
  푸는 문제는 그대로 손글씨 숫자 맞히기다
- **MNIST를 다른 것으로 바꾸면** — 예를 들어 CIFAR-10으로 바꾸면,
  **더 이상 손글씨 문제가 아니다.** 푸는 문제 자체가 바뀐다

## softmax는 학습되지 않는다

이것도 헷갈렸던 부분이다.
모델 안에 있으니 뭔가 학습될 것 같은데, softmax에는 **학습되는 값(파라미터)이 없다.**

정해진 계산을 그대로 할 뿐이다. 들어온 점수를 전부 양수로 만들고, 합이 1이 되게 나눈다.
학습으로 바뀌는 것은 그 앞 층들이고, softmax는 마지막에 모양만 바꿔주는 자리다.

## 정리

- 비교하기 전에 **같은 층위인지**부터 본다. 함수와 데이터셋은 나란히 놓을 수 없다
- MNIST = 재료(문제), softmax = 출력 형식(답을 내놓는 방식)
- 점수 → 확률 변환이 softmax가 하는 일 전부다
- softmax에는 학습되는 값이 없다
