> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

MNIST 분류기를 돌리려는데 이 컴퓨터에 torch가 없었다.
파이썬은 3.14인데, PyTorch 휠은 3.14용이 아직 불안정하다.

## `pip install` 을 안 했다

`uv` 로 이렇게 돌렸다.

```
uv run --python 3.12 --with torch --with torchvision python mnist.py
```

`uv` 가 **파이썬 3.12를 따로 받아서 거기서 돌린다.**
시스템 파이썬은 안 건드리고, `pip install` 도 안 했다.

3.14를 쓰는 내 컴퓨터에 3.14용이 없는 라이브러리를 억지로 넣는 대신,
3.12짜리 방을 따로 만들어 거기서만 돌린 셈이다.

## 그런데 에러가 났다

준비 단계에서 `uv python install 3.12` 를 돌렸더니 이렇게 나왔다.

```
error: Missing expected target directory for Python minor version link
```

`error` 라고 적혀 있으니 실패한 줄 알았다. 아니었다.

## 실제로는 설치가 끝나 있었다

**파이썬 3.12는 이미 받아져 있었다.**
실패한 것은 마지막 단계, 링크를 만드는 부분뿐이었다(윈도우 심볼릭 링크 권한 문제).

그냥 다시 실행하니 정상 동작했다.

## 알게 된 것

**에러 메시지는 "어느 단계에서 멈췄는지"를 말하지, "아무것도 안 됐다"를 말하지 않는다.**

설치처럼 여러 단계로 이뤄진 작업은 앞 단계가 다 끝난 뒤 마지막에서 걸릴 수 있다.
그때 화면에는 `error` 한 줄만 남는다.

그래서 에러를 봤을 때 바로 포기하거나 다른 방법을 찾기 전에,

- 메시지가 **무엇을 하려다** 실패했다고 말하는지 읽는다
  (여기서는 `link` — 받는 것이 아니라 링크 만들기였다)
- **결과물이 실제로 있는지** 확인한다
- 한 번 더 실행해본다

이번엔 세 번째로 풀렸다. 메시지를 믿고 포기했으면 없는 문제를 붙잡고 있었을 것이다.
