> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

이미지 인식의 역사를 정리하다가 걸린 대목이 있다.
**층을 더 쌓았더니 성적이 더 나빠진 구간**이 있었다는 것.

층이 깊을수록 복잡한 걸 배울 수 있으니, 깊게 쌓으면 좋아져야 정상이다.
안 좋아지는 것도 아니고 **나빠졌다.**

## 과적합이 아니었다

처음 의심할 것은 과적합이다. **훈련 데이터 성적과 새 데이터 성적이 벌어지는 것**,
이해하는 대신 외워버린 상태다.

깊은 모델이 데이터를 외워버렸다면 그 설명이 맞다. 그런데 아니었다.

**깊은 쪽은 훈련 데이터에서마저 못 맞혔다.**

외운 거라면 최소한 외운 문제는 맞혀야 한다. 그것도 못 맞혔다는 건
**외운 게 아니라 배우지를 못한 것**이다. 과적합이 아니라 학습 자체가 안 된 것이었다.

## 1보다 작은 값을 수백 번 곱하면

원인은 기울기였다.

**기울기**는 "이 숫자를 조금 바꾸면 결과가 얼마나 달라지는가"다.
학습은 뒤에서 앞으로 이 값을 전달하면서 각 층의 숫자를 고친다.

전달될 때 층마다 곱해진다. 그 값이 1보다 작으면,

```
0.9 를 100번 곱하면  →  0.000027
```

앞쪽 층에 도착할 때쯤이면 거의 0이다.
**"바꿔봤자 결과가 안 달라진다"는 신호**만 남는다. 그러니 앞쪽 층은 안 고쳐진다.

이게 **Vanishing Gradient(기울기 소실)** 다. 깊을수록 곱하는 횟수가 늘어나니 깊을수록 심해진다.

## 지름길 하나로 뚫렸다

해법은 **Skip connection** — 몇 개 층을 건너뛰어 입력을 그대로 흘려보내는 지름길이다.

기울기가 이 지름길로도 흐른다. 층을 거치며 곱해지는 경로 말고,
곱해지지 않고 바로 가는 경로가 하나 생긴 것이다.

## 잔차 — 층에게 나머지만 만들게 한다

관점을 하나 더 바꿨다.

층에게 정답 `H(x)` 를 통째로 만들라고 하는 대신,
**입력 `x` 를 뺀 나머지 `F(x)` 만** 만들게 한다. 이 나머지가 **잔차(Residual)** 다.

```
H(x) = F(x) + x
```

`x` 는 지름길로 그대로 온다. 층은 `F(x)` 만 담당한다.

이 구조가 왜 좋은지는 **항등 변환**을 생각하면 보인다.
항등 변환은 입력을 그대로 내보내는 것이다. 층을 쌓아도 최소한 나빠지진 않으려면
남는 층들이 "아무것도 안 하기"를 할 수 있어야 한다.

- 보통 구조에서 아무것도 안 하기 = 입력을 그대로 재현하는 법을 **배워야** 한다. 어렵다
- 잔차 구조에서 아무것도 안 하기 = **`F(x)` 를 0으로 만들면 된다.** 쉽다

쓸모없는 층은 0으로 꺼두면 그만이니, 깊게 쌓아도 손해가 안 난다.

## 정리

| | |
|---|---|
| 증상 | 층을 더 쌓으니 성적이 나빠졌다 |
| 과적합인가 | 아니다. **훈련 데이터에서도** 못 맞혔다 |
| 원인 | 1보다 작은 기울기가 층마다 곱해져 앞쪽까지 못 간다 |
| 해법 | 건너뛰는 지름길. 층은 나머지(`F(x)`)만 만든다 |
| 되는 이유 | 필요 없는 층은 `F(x)` 를 0으로 만들면 저절로 꺼진다 |
