하루 동안 화면 때문에 붙잡힌 시간이 기능 만든 시간보다 길었다.
공통점이 있었다. **고친 것은 맞는데 화면이 그대로였다.**

원인은 매번 달랐다.

## 1. 브라우저가 예전 CSS를 들고 있었다

표 모양을 잡으려고 `styles.css`를 고쳤는데, 화면이 하나도 안 바뀌었다.
파일을 다시 열어봐도 내용은 새것이다. 서버에 올라간 것도 새것이다.
**브라우저만 옛날 것을 들고 있었다.**

브라우저는 한 번 받은 CSS·JS를 저장해두고 재사용한다.
주소가 같으면 "이미 받은 거네" 하고 다시 받지 않는다.

해결은 **주소를 바꿔주는 것**이다.

```html
<link rel="stylesheet" href="styles.css?v=28">
```

`?v=28` 뒤의 번호를 올리면 브라우저가 보기에 다른 주소가 되어 새로 받는다.
파일 자체는 그대로다. 지금 이 프로젝트의 번호는 `v=28`이고,
**CSS나 JS를 고칠 때마다 이 번호를 올린다.**

> 파일을 고쳤는데 화면이 그대로면, 코드를 다시 보기 전에 이걸 먼저 의심한다.

## 2. `[hidden]`이 CSS에 졌다

`삭제할까요?` 하고 묻는 창이 **처음부터 계속 떠 있었다.**
숨기라고 해뒀는데 숨지 않았다.

HTML에는 `hidden`이라는 속성이 있다. 붙이면 안 보인다.
그런데 이건 브라우저가 기본으로 주는 규칙이고, **내가 쓴 CSS가 더 세다.**

```css
.확인창 { display: flex }
```

이렇게 써두면 `hidden`이 붙어 있어도 `display: flex`가 이겨서 계속 보인다.
`hidden`은 `display: none`을 붙여주는 것인데, 내 규칙이 그걸 덮어쓴 것이다.

그래서 한 줄을 따로 적었다.

```css
.확인창[hidden] { display: none }
```

**숨기는 규칙을 내가 다시 써주는 것**이다.
이건 예전에 다른 프로젝트에서도 한 번 겪었는데 또 만났다.
`display`를 지정한 요소에 `hidden`을 쓰면 늘 이 문제가 생긴다.

## 3. 확인창이 아예 안 떴다

삭제 버튼을 눌렀는데 아무 일도 일어나지 않았다. 오류도 없다.

`confirm()`을 쓰고 있었다. 브라우저가 띄워주는 `확인 / 취소` 창이다.

```js
if (!confirm("정말 지울까요?")) return;
```

**이 브라우저에서 그 창이 뜨지 않았다.** 안 뜨면 `confirm()`은 "취소"를 돌려준다.
그래서 삭제가 매번 조용히 취소되고 있었다. 눌러도 아무 일 없는 것처럼 보인 이유다.

고친 방법은 **브라우저에게 안 맡기는 것**이다.

- `삭제`를 한 번 누르면 → 버튼이 `정말 지울까요?`로 바뀐다
- 한 번 더 누르면 → 지워진다

내가 만든 화면이라 어디서든 뜬다.
나중에 장부 삭제 확인창도 같은 이유로 직접 만들었다.

## 4. 표가 본문 폭에 갇혔다

간편장부는 열이 8개다. 그런데 블로그처럼 생긴 본문 폭(`30rem`) 안에 들어가니
글자가 한 글자씩 세로로 쪼개져 나왔다.

표만 창 전체 폭으로 넓히면 되는데, 여기서 또 하나 걸렸다.

**`100vw`는 세로 스크롤바가 차지하는 자리까지 세어버린다.**
그래서 표가 창보다 살짝 넓어지고, 페이지 전체가 옆으로 밀린다.

`100vw` 대신 **실제 폭을 코드로 재서** 넣었다.
표를 그리고 나면 스크롤바가 생겨 폭이 또 달라지므로, **표를 그린 뒤에 한 번 더 잰다.**

## 5. 안내 문구가 화면 밖에 있었다

"저장했습니다" 같은 문구를 페이지 맨 아래에 뒀더니, 스크롤을 내려야 보였다.
사용자는 저장이 됐는지 안 됐는지 알 수 없었다.

- 문구를 **화면 구석에 떠 있게** 했다
- **1.2초 뒤 저절로 사라진다**
- 문구가 아래 버튼을 가리지 않게 `pointer-events: none`을 줬다

마지막 줄이 중요했다. 문구가 떠 있는 동안 그 자리의 버튼이 안 눌렸다.
**보이기만 하고 클릭은 통과시키는 것**이 `pointer-events: none`이다.

## 배운 것

다섯 개 다 "코드는 맞는데 화면이 다르다"였고, 원인은 한 번도 코드가 아니었다.

- 브라우저가 옛 파일을 들고 있거나
- 내 CSS가 브라우저 기본 규칙을 이기거나
- 브라우저가 창을 안 띄워주거나

**화면은 내 코드와 브라우저가 같이 만드는 것**이라는 걸 이번에 제대로 알았다.
내가 쓴 것만 보고 있으면 원인이 안 보인다.
