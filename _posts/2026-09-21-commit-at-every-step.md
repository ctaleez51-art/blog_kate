실험을 여러 번 돌리는 동안 커밋이 안 쌓이고 있었다.
파일은 계속 바뀌는데 기록이 하나도 안 남는 상태였다.

**고칠 때마다 커밋하지 않으면 깃을 쓸 이유가 없다**고 짚었다.
이후로는 **저장 → 커밋**을 한 묶음으로 반복했다.

## 돌아갈 지점이 있으니 과감해졌다

효과가 바로 나왔다. 커밋이 쌓이기 시작하니 설정을 마음 놓고 바꿀 수 있었다.

참조 모드를 원본으로 바꿔보는 실험도, 커밋이 없었으면 망설였을 것이다.
망가지면 어디까지 되돌려야 할지 모르니까. 돌아갈 지점이 있으면
**"해보고 아니면 되돌리지"** 가 된다.

실험 설정이 제출값과 달라진 것도 커밋 기록이 있으니 비교해서 알아챌 수 있었다.

## 노트북은 Ctrl+S 를 눌러야 결과가 들어간다

노트북(`.ipynb`)에서 한 번 걸렸다.

**VS Code 에서 셀을 실행하면 결과가 화면에 뜨지만, 그것만으로는 디스크에 안 적힌다.**
`Ctrl+S` 를 눌러야 실행 결과까지 파일에 기록된다.
저장 전에 커밋하면 **결과 없는 노트**가 올라간다.

확인은 탭을 보면 된다.

| 탭 표시 | 뜻 |
|---|---|
| ● (점) | 저장 안 됨. 지금 커밋하면 결과가 안 들어감 |
| `M` | 저장됨, 깃이 수정으로 인식함. 커밋 가능 |

점이 사라지고 `M` 으로 바뀌면 저장된 것이다.

## 노트북 파일을 다룰 때

결과 이미지가 박히면 노트북이 커진다. 어제는 1.35MB 까지 갔다.
한 셀만 고치겠다고 통째로 열면 낭비라서, 파이썬으로 해당 셀만 갈아끼웠다.

```python
import json
nb = json.load(open("pose_tool.ipynb", encoding="utf-8"))
nb["cells"][5]["source"] = 새_내용
json.dump(nb, open("pose_tool.ipynb", "w", encoding="utf-8"),
          ensure_ascii=False, indent=1)
```

`.ipynb` 는 결국 JSON 이고 `cells` 가 셀 목록이라 이게 된다.
`ensure_ascii=False` 를 빼면 한글이 전부 이스케이프 문자로 바뀌어 diff 가 엉망이 된다.

## 커밋 메시지에 따옴표를 안 쓴 이유

PowerShell 의 here-string 으로 커밋 메시지를 넘길 때, **메시지 안에 큰따옴표가 있으면 깨진다.**
엉뚱하게 이런 오류가 난다.

```
error: pathspec '...' did not match any file(s) known to git
```

따옴표 때문이라는 말이 어디에도 안 나와서 한참 봤다.
어제는 그냥 커밋 메시지에 따옴표를 안 썼다.

## 남길 것

- 고칠 때마다 커밋한다. 안 쌓이면 되돌릴 수도, 비교할 수도 없다
- 노트북은 **실행 ≠ 저장**이다. 탭의 점이 사라진 걸 보고 커밋한다
- 오류 메시지가 원인을 가리키지 않을 때가 있다. `pathspec` 오류가 따옴표 문제였다
