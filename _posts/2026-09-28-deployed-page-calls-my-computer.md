말로 간편장부를 쓰는 PoC 를 만들었다. 구조가 이렇다.

| 부분 | 어디서 도나 |
|---|---|
| 화면 | GitHub Pages (공개 https 주소) |
| 받아적기(Whisper) | 내 노트북 |
| 칸 나누기(젬마) | 내 노트북 |

소리와 장부를 밖으로 안 내보내려고 일부러 이렇게 짰다.
그런데 **공개된 페이지가 내 컴퓨터를 부르는 것**이 그냥은 안 됐다.

## 403 — 누가 불러도 되는지를 서버가 정한다

배포 주소에서 젬마를 부르면 `403` 이 돌아왔다.
Ollama 자체는 멀쩡히 떠 있었다. `/api/tags` 는 200 이었다. 프리플라이트만 막혔다.

Ollama 는 **어느 사이트가 자기를 불러도 되는지**를 `OLLAMA_ORIGINS` 로 제한한다.
내 배포 주소가 거기 없으니 막은 것이다.

**[파워셸에 칠 것]**

```powershell
setx OLLAMA_ORIGINS "https://ctaleez51-art.github.io"
```

## 여기서 한 번 더 막혔다 — `setx` 는 언제부터 먹나

값을 저장했는데도 계속 403 이었다.
확인해 보니 **저장은 돼 있고, 지금 도는 Ollama 가 그 값을 안 물고 있었다.**

`setx` 는 레지스트리에 써두는 것이라 **그 뒤에 새로 켜지는 프로세스부터** 적용된다.
이미 떠 있던 Ollama 는 옛 환경을 그대로 들고 있었다.

더 헷갈린 건, **`setx` 이전에 열어둔 파워셸 창에서 Ollama 를 껐다 켰을 때도** 안 먹었다는 것이다.
그 창 자체가 옛 환경을 들고 있으니, 거기서 띄운 자식 프로세스도 옛 환경을 물려받는다.

| 어디서 켰나 | 먹나 |
|---|---|
| `setx` 이전에 열린 창에서 | ✕ 그 창의 옛 환경을 물려받는다 |
| `setx` 이후에 새로 연 창에서 | ○ |
| 시작 메뉴에서 앱으로 | ○ |

**환경변수를 바꾸면 "프로그램을 껐다 켠다" 로는 부족하다. 켜는 쪽 창도 새로 열어야 한다.**

전에 Supabase 토큰을 다룰 때 환경변수 수명 문제를 한 번 겪었는데,
그때는 "이 창에서만 산다" 쪽이었고 이번은 **"언제 열린 창이냐"** 쪽이었다.

## 하나 더 — 공개 페이지가 사설망 주소를 부르는 것

공개 https 페이지가 `127.0.0.1` 같은 **사설망 주소**를 부를 때,
크롬은 프리플라이트에서 그 서버가 허락했는지를 따로 확인한다.
바깥 사이트가 남의 집 안쪽 기기를 마음대로 찔러보는 걸 막으려는 것이다.

받아적기 서버에 응답 헤더를 하나 붙였다.

```python
self.send_header("Access-Control-Allow-Private-Network", "true")
```

## 남길 것

**403 은 "서버가 죽었다" 가 아니라 "이 부름을 허락 안 했다" 다.**
그래서 서버가 살아 있는지(`/api/tags` 200)와 내 부름이 통과하는지는 따로 확인한다.

환경변수를 고쳤는데 안 먹으면 **값이 틀린 건지, 적용될 창이 아닌 건지**부터 가른다.
저장은 됐는데 안 먹는 경우가 따로 있다.
