> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

배포된 사이트에서 내 목소리로 10문장을 말했다. TTS 가 아니라 실제 사람 목소리다.

| | |
|---|---|
| 맞은 건 | **7 / 10** |
| 받아적기 | 합계 54.5초, 한 건 5.5초 |
| 칸 나누기 | 합계 189.5초, 한 건 **19.0초** |
| 합 | 한 건 **24.4초** |

성공 기준을 10건 중 10건으로 잡아놨으니 **못 미쳤다.** 그대로 적었다.

## 칸 나누기가 전체의 78%

젬마를 미리 깨워두고(`keep_alive`) 재도 19초였다.
모델을 올리는 시간이 아니라 **GPU 가 없어서** 나는 시간이다.

앞서 문서에 "한 건 7초" 라고 적혀 있었는데 실측은 18~19초였다. 숫자를 실측으로 고쳤다.
재보기 전에 적힌 숫자는 재본 숫자가 아니다.

## 틀린 세 건 — 이게 제일 쓸모 있었다

**세 건이 다 다른 이유로 틀렸다.**

### ① 받아적기가 뭉갠 것

> 말한 것: "프린터 토너 1개를 **공급가액 50,000원**, 부가세 5,000원에"
> 받아적은 것: "프린터 **톤의 한계를 공급가에 고마른** 부가세 5천원에"

공급가액 숫자가 통째로 사라졌다. 남은 숫자가 부가세 5,000 뿐이니
젬마가 그걸 금액에도 넣었다. **앞이 틀리면 뒤는 손쓸 수 없다.**
한 문장에 숫자를 둘 넣었더니 중간을 흘렸다.

### ② 상호를 잘못 들은 것

`배달의민족` → `배달이 민족`.
고유명사라 Whisper 가 약하다. 날짜·금액·구분은 다 맞았고 거래처 한 칸만 틀렸다.

### ③ 받아적기는 맞았는데 젬마가 틀린 것

`12월 5일` 을 제대로 받아적었는데 젬마가 일자에 **오늘 날짜**를 넣었다.

금액도 틀렸다. "공급가액 30만원, 부가세 3만원" 이라 공급가액이 이미 나왔는데
젬마가 거기서 부가세를 **또** 빼서 270,000 으로 만들었다.
"총액과 부가세를 같이 말하면 빼라" 는 규칙을 **총액이 아닌 공급가액에도** 적용한 것이다.

## 고칠 데가 셋 다 다르다

| | 틀린 곳 | 고치는 방향 |
|---|---|---|
| ① | 받아적기 | 말하는 방식이나 모델 크기 |
| ② | 받아적기 | 거래처 목록을 미리 주기 |
| ③ | 칸 나누기 | 지시문 한 줄 |

**셋 다 "틀렸다" 로 뭉뚱그리면 고칠 데를 못 찾는다.**
"정확도 70%" 한 줄만 남겼으면 ①·②·③ 중 어디에 손을 대야 하는지 알 수 없었다.

두 단계를 이어붙인 구조라서 더 그렇다.
**어느 단계에서 틀렸는지를 단계별 산출물로 갈라놔야** 틀린 건수가 정보가 된다.
