작업 폴더에 `.git` 이 언제 생겼는지는 알아냈다(9/29 11:38). 이번엔 **누가** 했는지를 대화 기록으로 찾아봤다. 결론부터 말하면 못 찾았다.

## 앱의 세션 검색 — 지운 대화는 안 나온다

`git init`, `Initialized empty Git repository`, `claudecode/.git` 으로 검색했다. 나온 건 10월 5일 세션 두 개뿐이었다.

**앱 목록에서 지운 대화는 앱 검색에 안 나온다.** 나는 대화 목록을 거의 다 지워 둔 상태였다.

## 대화 파일을 직접 읽기

목록에서 지워도 대화 파일(`.jsonl`)은 PC에 남아 있다. 47개였다.

- 파일 안에 `git init` 이라는 글자는 여러 번 나왔다. 그런데 전부 **글 속 설명**이었다
- **실제로 실행한 명령**(도구 호출의 `command` 칸)만 골라 보니 `git init` 은 하나도 없었다
- 9월 29일 것은 작은 정보 파일만 있고 대화 내용 파일이 없었다
- 9월 29일이 언급된 대화 파일 두 개는 10월 2일 대화였다

그래서 **언제 생겼는지까지만 확인됐고, 누가 했는지는 알 수 없었다.**

## 남길 것

- 글자 검색에 걸렸다고 그 명령이 실행된 건 아니다. **실행 기록과 언급을 나눠서** 본다
- 대화를 지우면 앱에서 원인을 추적할 길도 같이 끊긴다
