> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

claude.ai 설정 → 계정 → **Claude 지침** 칸에 내 정보와 원하는 방식을 길게 적어 뒀다. 그런데 Code 탭에서 일할 때 그 내용을 아는 것 같지 않았다.

## 설정 화면에 답이 있었다

설정 칸 설명에 지침을 "채팅과 Cowork 전반에 걸쳐" 기억한다고 적혀 있었다. **Code 탭은 들어 있지 않았다.**

실제로 Code 창에 들어온 것은 `CLAUDE.md` 와 계정 이메일뿐이었다.

## 같은 일을 하는 곳이 세 군데였다

| 기능 | 저장 위치 | 어디에 반영되나 |
|---|---|---|
| 설정의 Claude 지침 | claude.ai 서버 | 채팅, Cowork |
| `CLAUDE.md` | PC의 작업 폴더 | Code 탭 |
| 메모리 폴더 | PC의 `.claude` 폴더 (작업 폴더 밖) | Code 탭 |

- 설정 지침은 PC 어디를 찾아도 파일로 나오지 않는다. **서버의 계정 안에** 있다
- 메모리 폴더 파일은 설정을 켠다고 저절로 생기지 않는다. **Claude가 써야 생긴다.** 나는 "메모리 폴더에 쓰지 말 것" 규칙을 걸어 뒀기 때문에 비어 있는 게 맞았다

Code 탭은 처음부터 PC 폴더 안에서 일하도록 만들어졌다. 그래서 서버 계정이 아니라 폴더 안의 파일을 읽는다.

## `CLAUDE.md` 와 메모리 파일의 차이

| | `CLAUDE.md` | 메모리 파일 |
|---|---|---|
| 위치 | 작업 폴더 안 | 작업 폴더 밖 |
| 누가 쓰나 | 내가 정해서 씀 | Claude가 알아서 씀 |
| 들어가는 방식 | 새 창을 열 때 통째로 | 새 창을 열 때 목록 파일만, 내용은 필요할 때 엶 |
| 무게 | 따라야 하는 지시 | 참고하는 배경 정보 |

## 남길 것

- 설정에 적었다고 모든 곳에 반영되는 게 아니다. **설정 칸의 설명에 적힌 범위**를 먼저 읽는다
- Code 탭에서 쓰려면 작업 폴더 안 파일로 옮긴다
