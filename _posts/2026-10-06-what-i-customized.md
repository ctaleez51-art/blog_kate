> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

Claude Code 데스크톱 앱을 쓰면서 앱이 기본으로 주는 방식을 그대로 쓰지 않고 몇 가지를 바꿨다. 계속 비교해 보려고 표로 정리했다.

| 항목 | 원래 앱 설정 | 내가 바꾼 설정 |
|---|---|---|
| 메모리 | 작업 폴더 밖 메모리 폴더에 Claude가 알아서 씀. 설정의 Claude 지침은 서버에 있고 Code 탭엔 안 들어옴 | 작업 폴더 안 `memory.md` 하나. 내가 허락한 것만 씀. 설정 지침도 여기로 옮김. `CLAUDE.md` 맨 위 `@memory.md` 줄로 새 창에 자동으로 들어감 |
| 실행 방식 | 수동 모드: 앱이 실행할 때마다 허락을 물음 | 자동 모드를 쓰고, 규칙으로 "설명하고 → 허락받고 → 실행" |
| 선택 창 | 앱이 띄우는 질문 창 | 앱 창은 안 쓰고, 마침표 하나를 입력하면 육하원칙 선택 창을 띄움 |

## 바꾼 이유

- **메모리:** 지시와 기억이 전부 작업 폴더 안에 있으면 서버나 숨은 폴더를 찾을 필요가 없다. Claude가 작업 폴더 밖에 접근할 이유도 없어진다
- **실행 방식:** 수동 모드는 허락 창이 너무 자주 뜬다. 대신 무엇을 할지 먼저 글로 듣고 허락한다
- **선택 창:** 앱 질문 창은 선택지를 앱이 정한다. 내가 정한 틀(육하원칙)로 고르고 싶었다

## 바꾸고 나서 생긴 차이

원래 방식은 앱이 알아서 넣어 주는 것이고, 내가 바꾼 방식은 **규칙 파일에 적어서** 따르게 하는 것이다. 적어만 두고 지키지 않으면 반영이 안 된다. 그래서 메모리는 문장 대신 `@` 줄로 바꿔 앱이 넣어 주게 했다.

## 남길 것

- 앱 기능을 바꿀 때는 **원래 어떻게 동작하는지**부터 적어 두고 나란히 비교한다
- 규칙으로만 따르게 한 것은 지켜지는지 계속 확인한다
