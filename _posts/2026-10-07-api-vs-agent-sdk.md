## SDK 가 뭔데

SDK 는 Software Development Kit(소프트웨어 개발 도구 모음)이다. 어떤 서비스를 내 코드에서 쉽게 쓰도록, 그 회사가 미리 만들어 나눠 주는 도구 묶음이다.

API, SDK, 라이브러리가 자꾸 섞여서 택배로 나눠 봤다.

| 말 | 택배로 치면 | 예 |
|---|---|---|
| API | 택배사의 접수 규칙. "보내는 사람, 받는 사람, 주소, 무게를 이 양식대로 적어 내라" | Claude 에게 요청하는 주소와 요청·답 모양 |
| SDK | 택배사가 나눠 주는 키트. 칸이 인쇄된 송장, 박스, 설명서. 그 택배사 전용 | `anthropic`, `claude-agent-sdk` |
| 라이브러리 | 테이프, 가위. 택배든 이사든 어디에나 쓰는 도구 | `json`, `pathlib` |

API 는 규칙이고, SDK 는 그 규칙을 몰라도 칸만 채우면 되게 해 주는 키트다. 다만 경계는 흐릿하다. `claude-agent-sdk` 도 설치되는 건 라이브러리 하나다.

## Claude API 와 Claude Agent SDK

이름이 비슷해서 "SDK 가 API 를 쉽게 쓰게 해 주는 것"으로만 생각했다. 그런데 Agent SDK 는 하는 일이 다르다. 핵심은 **다음에 무엇을 할지 누가 정하느냐**다.

같은 일로 비교해 봤다. 할 일은 "영수증 PDF 를 읽어서 장부에 넣기".

**API 로 만들면 — 순서를 내 코드가 정한다**

1. 내 코드가 PDF 를 연다
2. 내 코드가 내용을 Claude 에게 보낸다. "날짜, 금액, 거래처를 뽑아 줘"
3. Claude 가 답한다. Claude 의 일은 여기서 끝이다
4. 내 코드가 그 답을 장부에 저장한다

Claude 는 2~3번 한 칸만 맡는다. PDF 가 흐릿하거나 이미 장부에 있는 영수증이면 어떻게 할지는 내가 미리 코드로 다 짜 둬야 한다.

**Agent SDK 로 만들면 — 순서를 Claude 가 정한다**

"이 영수증을 장부에 넣어 줘"라고만 맡긴다.

1. 파일을 열어 본다 → "글자가 아니라 사진이네. 사진으로 읽어야겠다"
2. 읽어 본다 → "날짜가 잘 안 보이네. 같은 폴더의 카드 명세서와 맞춰 봐야겠다"
3. 명세서를 열어 날짜를 찾는다
4. 장부를 열어 본다 → "같은 금액이 이미 있네. 중복인지 확인해야겠다"
5. 확인한 뒤 넣고, 잘 들어갔는지 다시 열어 본다

이 순서는 내가 짜지 않았다. 앞 단계에서 본 것을 보고 Claude 가 다음 단계를 골랐다. Claude Code 처럼 움직이는 프로그램을 내 코드로 만드는 도구가 Agent SDK 다.

## 나란히 놓으면

| | Claude API | Claude Agent SDK |
|---|---|---|
| 하는 일 | 질문 하나 → 답 하나 | 일을 맡기면 읽기·실행·확인을 스스로 반복 |
| AI 가 쓸 도구 | 내가 만들어 연결 | 파일 읽기·쓰기, 명령 실행 등이 이미 들어 있음 |
| 보내는 내용 | 내가 넣은 것만 | 넣은 것 + Claude Code 가 덧붙이는 숨은 내용 |
| 프로그램에 넣을 때 | 코드만 | `claude.exe` 도 같이 |

API 로도 여러 단계를 만들 수는 있다. 다만 그 반복 과정을 내가 직접 짜야 한다.

## CLI 와는 뭐가 다른가

"Claude Code 명령어(CLI)보다 SDK 가 프롬프트를 세밀하게 넣을 수 있다"는 말을 들었다. 반만 맞다.

SDK 는 안에서 CLI 를 실행해서 돈다. 지시문 바꾸기(`--system-prompt`), 덧붙이기(`--append-system-prompt`), 모델 고르기(`--model`)는 CLI 에서도 된다.

SDK 가 나은 건 **코드로 다룰 수 있다**는 점이다.

- 지시문과 질문을 바꿔 가며 12번 반복하고 결과를 파일에 저장하기
- 돌아온 메시지를 종류별(생각, 답, 결과)로 나눠 받기
- 파이썬 함수를 Claude 가 쓸 도구로 넣기
- Claude 가 도구를 쓰기 직전에 끼어들어 막거나 승인받기

## 남길 것

- API 는 규칙, SDK 는 그 규칙을 쉽게 쓰게 해 주는 키트, 라이브러리는 어디에나 쓰는 도구
- Claude API 와 Agent SDK 를 가르는 건 "다음 단계를 누가 정하나"
- 내 앱에 무엇을 쓸지는 AI 가 맡을 일이 정해진 뒤에 고른다. 한 번 묻고 한 번 받는 일인지, 스스로 여러 단계를 진행해야 하는 일인지
