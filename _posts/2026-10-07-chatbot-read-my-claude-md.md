> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 이상한 답들

단순 챗봇에게 폴더를 만들고 지우게 하는 실습을 했다. 같은 부탁을 했는데 답이 매번 달랐고, 그중 몇 개는 이상했다.

```
Claude: 규칙 4에 따라 저는 삭제를 하지 않습니다.
```

```
Claude: sub1 폴더는 아직 만들지 않았습니다. 제가 명령을 실행하면 승인 창이 뜰 수 있어서(규칙 5),
직접 입력하실 PowerShell 명령어를 드립니다.
```

```
Claude: PowerShell에서 아래 명령을 실행할 생각입니다. ... 진행할까요?
```

"규칙 4", "규칙 5"는 내가 데스크톱 앱에서 쓰려고 `CLAUDE.md` 에 적어 둔 규칙이다.

| 내 규칙 | 챗봇의 행동 |
|---|---|
| 4. 삭제는 절대 하지 말 것 | 삭제를 거절 |
| 5. 창을 띄우지 않는다 | 허락 설정을 넣어도 실행 안 하고 명령어만 줌 |
| 9. 설명하고, 허락받고, 실행한다 | "진행할까요?"라고 묻기만 함 |

## 왜 챗봇이 내 규칙을 아나

Claude Agent SDK 는 Claude Code 를 거쳐서 돈다. Claude Code 는 실행한 폴더부터 위쪽 폴더로 올라가며 `CLAUDE.md` 를 찾아 읽는다.

실습 폴더 `TEST` 가 내 작업 폴더 `claudecode` 안에 있었다. 그래서 `TEST` 에서 실행한 챗봇도 위쪽의 내 `CLAUDE.md` 를 읽고 그 규칙을 따랐다.

코드에 "폴더 만들기는 허락 없이 해도 된다"고 넣어도, 챗봇이 스스로 "창을 띄우면 안 되니 실행하지 말아야지" 하고 멈췄다. 프로그램 설정은 풀었는데, 챗봇이 읽은 규칙이 한 번 더 막은 것이다.

## 다른 수강생과 뭐가 다른가

삭제는 다른 사람에게도 처음엔 막힌다. 다만 막는 주체가 다르다.

| | 다른 수강생 | 내 환경 |
|---|---|---|
| 처음 막는 것 | Claude Code 기본 설정(실행 전 승인 필요) | 같음 |
| 코드에서 허락하면 | 풀린다 | 내 `CLAUDE.md` 규칙 때문에 챗봇이 또 거절 |

실습이 의도한 흐름은 "코드에서 허락을 주면 풀린다"인데, 내 환경에서는 한 겹이 더 있었다.

## 푸는 방법 두 가지

**코드에서 — `setting_sources=[]`.** 설정 파일을 하나도 읽지 말라는 설정이다.

```python
ClaudeAgentOptions(..., setting_sources=[])
```

넣고 다시 시키자 규칙 4 이야기 없이 삭제를 시도했다.

**규칙 파일에서 — 실습 동안만 예외.** 코드를 늘리기 싫어서, `CLAUDE.md` 에 이 실습을 하는 동안만 규칙 3·4·5·9 를 적용하지 않는다는 섹션을 넣었다. 그러자 챗봇이 이렇게 답했다.

```
Claude: Empty folder; TEST exception waives rule 4 here.
Claude: TEST\sub1 폴더를 삭제했습니다. ... TEST 폴더에서 하는 추가 실습 중에는
그 규칙이 적용되지 않아서 바로 지웠습니다.
```

실습이 끝나고 예외 섹션은 지웠다.

## 규칙을 고를 때

예외를 넣을 때 처음엔 상관없는 규칙까지 끼어들었다. 존댓말 규칙은 챗봇 말투만 바꿀 뿐 폴더 실습 결과와는 상관없다. 작업 폴더 밖 접근 금지도 `TEST` 가 작업 폴더 안이라 걸릴 일이 없다. 실제로 결과를 바꾼 건 4·5·9 였다. 3 은 혹시 몰라 같이 뺐다.

## 남길 것

- SDK 로 만든 프로그램도 Claude Code 를 거치면 실행 폴더 위쪽의 `CLAUDE.md` 를 읽는다
- 실습 결과가 남들과 다르면 내 환경에만 있는 것부터 의심한다
- 남들과 같은 조건으로 실험하려면 `setting_sources=[]` 를 넣거나, 실습 폴더를 내 규칙 밖에 둔다
- 규칙을 잠시 끌 때는 결과에 실제로 영향을 주는 것만 고르고, 끝나면 되돌린다
