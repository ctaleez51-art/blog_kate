> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 답만 보면 안 보이는 것

배송 문의 실험을 12번 돌리고 결과 파일을 열었다. 답 글(`answer_parts`)만 보지 않고, 같이 남은 실행 기록(`events`)의 마지막 줄 `ResultMessage` 까지 봤다. 여기에 토큰 수와 비용이 들어 있다.

A 첫 번째 시도의 숫자는 이렇다.

| 항목 | 값 |
|---|---|
| 입력 토큰 | 3,364 |
| 출력 토큰 | 654 |
| 그중 속으로 생각한 양 | 480 |
| 비용 | 약 0.0076달러 |

## 입력이 왜 3,364 인가

내가 넣은 것은 지시문과 질문뿐이다. 합쳐도 100토큰 남짓이다. 그런데 입력은 매번 약 3,360토큰이었다.

Claude Agent SDK 는 Claude 를 직접 부르지 않고 Claude Code 프로그램을 거쳐서 부른다. 그 과정에서 보이지 않는 내용이 덧붙는다. 정확히 무엇인지는 확인하지 못했지만, Claude Code 의 기본 지시로 보인다.

이 숨은 입력이 결과에도 흔적을 남긴 것 같다. 맥락 없이 "아직 없어요"만 받은 조건(C)에서 모델이 "어떤 작업이나 프로젝트냐", "프로젝트 파일이 없다는 뜻이냐"고 물었다. 배송 상담 실험에서 "프로젝트 파일"이 나올 이유는 없다. 그래서 이 실험은 "지시만 바꾼 비교"라고 하기엔 완전히 깨끗하지 않다.

## 출력은 대부분 안 보이는 생각

출력 654 중 화면에 보이는 답 글은 170토큰 정도이고, 480은 답하기 전에 속으로 생각한 양이다. 출력 요금도 대부분 보이지 않는 곳에 쓰였다.

## 12번에 얼마

| 조건 | 한 번 비용 |
|---|---|
| A, B | 약 0.006~0.008달러 |
| C | 약 0.007~0.008달러 |
| D | 약 0.009~0.011달러 |

합치면 약 0.094달러(약 130원)다. 요약을 넣어서 입력이 조금 길고, 생각도 오래 한 D 가 가장 비쌌다.

## 질문 하나에 비싸 보인 이유

질문 자체가 비싼 게 아니었다. **숨은 입력과 숨은 생각**이 비용의 대부분이다.

Agent SDK 는 원래 도구를 쓰며 여러 단계로 일하는 에이전트용이라 이런 덧붙임이 있다. 질문 하나에 답 하나만 받는 일이라면 API 를 바로 부르는 쪽이 넣은 만큼만 낸다.

같은 SDK 라도 설정을 하나도 안 주면 기본 모델(Opus)로 돈다. 추가 실습에서 단순 챗봇을 그렇게 돌렸더니 질문 한 번에 약 0.13달러였다. Haiku 로 고정한 이번 실험의 한 번 비용보다 열 배 넘게 비싸다.

## 남길 것

- 결과 파일은 답만 보지 않고 실행 기록의 숫자까지 본다
- 내가 넣은 것과 실제 입력이 다를 수 있다. 차이가 크면 그 차이가 결과에도 섞인다
- 모델을 정하지 않으면 기본값으로 돈다. 비용은 모델에 따라 열 배씩 차이 난다
