> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 역할(role)

모델에 보내는 대화에는 **"이 말을 누가 했는지"**를 표시하는 칸이 있다.

| 역할 | 누구의 말 | 예 |
|---|---|---|
| system | 앱 만든 사람이 주는 지시. 대화 전체에 적용 | "한국어로 답한다. 정중한 상담 톤으로 답한다." |
| user | 사용자가 한 말 | "배송일은 언제인가요?" |
| assistant | AI 가 한 말 | "죄송하지만 확인할 수 없습니다…" |

Claude API 에서는 system 이 대화 칸이 아니라 따로 떨어진 설정으로 들어간다. 대화 칸의 역할은 user 와 assistant 둘이다. AI 가 도구를 썼을 때 그 결과는 user 칸 안에 "도구 결과"로 넣는다. 다른 회사는 `developer`, `tool` 같은 역할을 따로 두기도 한다.

실습 코드에 대 보면 이렇다.

```python
options = ClaudeAgentOptions(system_prompt=SYSTEM_A)   # system
query(prompt=user_input, options=options)              # user
# 돌아온 AssistantMessage                               # assistant
```

## 내 CLAUDE.md 는 시스템 프롬프트인가

데스크톱 앱에서 나는 `CLAUDE.md` 파일에 규칙을 적어 둔다. 이게 시스템 프롬프트인 줄 알았다.

물어보니 아니었다. 들어가는 칸은 **대화 첫 user 칸**이다. "이 지시가 기본 동작보다 우선한다"는 안내와 함께 들어가기 때문에, 모델은 시스템 프롬프트처럼 지킬 규칙으로 받아들인다. 하지만 자리는 user 다.

시스템 프롬프트 자리에는 Claude Code 가 원래 가진 기본 지시(도구 쓰는 법, 안전 규칙 등)가 있다.

| 어디서 | 시스템 프롬프트를 직접 넣을 수 있나 |
|---|---|
| 코드(API, SDK) | 된다. `system_prompt=` |
| Claude Code 명령어(CLI) | 된다. `--system-prompt`(바꾸기), `--append-system-prompt`(덧붙이기) |
| 데스크톱 앱 | 넣는 칸이 없다. 그래서 `CLAUDE.md` 같은 파일로 지시를 넣는다 |

처음엔 "사용자는 시스템 프롬프트를 고칠 수 없다"는 답을 들었는데, 그건 데스크톱 앱 기준이었다. 코드와 CLI 에서는 넣을 수 있다.

## 프롬프트 엔지니어링과 컨텍스트 엔지니어링

수업에 두 말이 같이 나와서 헷갈렸다. 프롬프트 엔지니어링이 컨텍스트 엔지니어링 안에 들어가는 관계다.

| | 프롬프트 엔지니어링 | 컨텍스트 엔지니어링 |
|---|---|---|
| 다루는 것 | 지시문을 어떻게 쓸지 | 입력 전체에 무엇을 넣고 뺄지 |
| 예 | 말투 지시, 예시, 답 형식 | 지시문 + 이전 대화 + 검색 자료 + 도구 결과 + 요약을 매번 고르기, 길어지면 무엇을 요약·제외할지 |
| 관심 | 한 번의 요청을 잘 쓰기 | 호출이 이어질 때 매번 입력을 잘 꾸리기 |

배송 실험에 대 보면 둘이 깔끔하게 갈린다.

- 상담 톤 → 기술 문서 톤으로 지시문 문장을 바꾼 비교: **프롬프트 엔지니어링**
- 이전 대화 요약을 넣을지 말지 정한 비교: **컨텍스트 엔지니어링**

AI 가 도구를 쓰며 여러 단계로 일하게 되면서, 지시문 문장만큼 "매번 무엇을 보여 줄지"가 중요해져서 따로 부르게 된 말이다.

## 덤 — Haiku 는 어떻게 읽나

**하이쿠**다. 일본의 짧은 시(5·7·5음절, 세 줄) 이름이다. Claude 모델 이름은 글의 길이로 크기를 나타낸다.

| 이름 | 뜻 | 모델 |
|---|---|---|
| Haiku(하이쿠) | 짧은 시 | 가장 작고 빠르고 저렴 |
| Sonnet(소네트) | 14줄 시 | 중간 |
| Opus(오퍼스) | 큰 작품 | 가장 큼 |

## 남길 것

- 역할은 "누가 한 말인지"를 표시하는 칸. Claude API 에서 system 은 따로 떨어져 있다
- 내 `CLAUDE.md` 는 시스템 프롬프트가 아니라 첫 user 칸에 들어간다. 역할은 비슷해도 자리는 다르다
- 지시문 문장을 다듬는 건 프롬프트, 매번 무엇을 넣을지 고르는 건 컨텍스트
