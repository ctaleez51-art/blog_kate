## 실험

"9.11과 9.9 중 어느 쪽이 더 큰가요?" (정답 9.9) 를 qwen3.5:2b 에 열한 가지 방법으로 물었다(`m11_experiment.py`). m2·m3·m4 의 질문 문장은 자료에 없어서 내가 만들었고, m5·m6·m7 은 자료 그대로 썼다.

| 번호 | 묻는 방법 | 최종 답 | 풀이 설명 | 자료와 |
|---|---|---|---|---|
| m1 | 그냥 (생각 끔) | 맞음 | 틀림 ("첫째 자리가 둘 다 9") | 같음 |
| m2 | 수학 교사 역할 + 검증 | 맞음 | 틀림 ("911/100 < 900/100") | 같음 |
| m3 | 단계별로 (CoT) | 맞음 | 흔들림 | 같음 |
| m4 | 비교 예시 두 개 (few-shot) | 맞음 | 대체로 맞음 (9.90 으로 자리 맞춤) | 같음 |
| m5 | 한 답 안에 세 풀이 + 다수결 | **틀림** (날짜로 읽음) | | 같음 |
| m6 | "소수점" 단어 금지 | 맞음 | 엉터리, "소숫점" 사용 | 다름 (자료는 오답) |
| m7 | JSON 으로 | 맞음 | 맞음, 파싱 성공 | 같음 |
| m8 | temperature 0 | 엉망 (앞뒤 모순) | | 다름 |
| m9 | temperature 1.5 | **틀림** ("같은 크기") | | 같음 |
| m10 | 생각 끔 | **틀림** (9월 11일) | | 다름 |
| m11 | 생각 켬 | 맞음 | 맞음 | 같음 |

## 결과에서 본 것

### 최종 답만 보면 속는다

최종 답이 맞은 것은 7개다. 그런데 **설명까지 맞은 것은 m4, m7, m11 셋뿐**이다. m1 은 "첫째 자리가 둘 다 9"라는 틀린 근거로 맞는 답을 냈고, m2 는 "911/100 < 900/100" 이라는 틀린 식을 썼다.

### 생각을 켜면 맞지만 오래 걸린다

생각하기를 켠 m2·m3·m7·m11 은 모두 최종 답이 맞았다. 대신 겉으로 보이지 않는 생각을 4,872~11,092자 더 만들었다. m2 는 몇 분을 기다렸다.

### 같은 조건인데 답이 달랐다

m1 과 m10 은 둘 다 "생각 끔"이고 조건이 같다. 그런데 m1 은 맞고 m10 은 틀렸다. temperature 를 따로 정하지 않으면 매번 달라질 수 있다.

### 한 가지 효과만 떼어 말할 수 없다

자료도 밝히듯 이 표는 생각 켜기·끄기 설정이 섞인 기록이다. 그래서 "CoT 를 쓰면 맞는다"처럼 방법 하나의 효과만 떼어 말할 수 없다.

## 이름 정리

| 이름 | 뜻 |
|---|---|
| CoT (Chain of Thought) | "단계별로 풀어라"라고 시키기 |
| few-shot | 푼 예시 몇 개를 먼저 보여 주기 |
| Self-Consistency | 여러 번 **따로** 물어서 가장 많이 나온 답 고르기 |

m5 는 Self-Consistency 와 다르다. 따로 여러 번 물은 게 아니라, 한 답 안에서 세 번 풀게 했다. 그리고 틀렸다.

## 남길 것

1. 헷갈릴 부분을 질문에 직접 밝힌다 ("소수로서 비교")
2. 푸는 예시를 보여 준다 (few-shot 인 m4 가 설명까지 맞았다)
3. 그래도 답은 따로 확인한다
