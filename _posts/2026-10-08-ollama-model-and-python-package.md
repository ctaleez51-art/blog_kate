> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 실습 모델 받기

`ollama list` 로 보니 내 컴퓨터에는 gemma4:e4b 와 gemma3:4b 만 있었다. 실습 자료대로 qwen3.5:2b 를 받았다.

```powershell
ollama pull qwen3.5:2b
```

받는 도중 100% 가 끝났는데 또 받는 것처럼 보였다. 모델은 파일 하나가 아니라 **여러 조각**이기 때문이다. 큰 조각(가중치) 뒤에 작은 조각(대화 틀, 설정, 라이선스)이 이어서 내려온다. 마지막에 `success` 가 나오면 끝이다.

## 젬마와 큐엔, 직접 확인한 차이

`ollama show 모델이름` 으로 하나씩 열어 봤다.

| 모델 | 만든 곳 | 매개변수 | 할 수 있는 것 |
|---|---|---|---|
| gemma3:4b | 구글 | 4.3B | 글, 이미지 |
| gemma4:e4b | 구글 | 8.0B | 글, 이미지, 소리, 도구, **생각하기**(기본으로 켜짐) |
| qwen3.5:2b | 알리바바 | 약 2B | 생각하기 있음 (실습 코드가 `"think": False` 로 끔) |

내 앱은 gemma3:4b 를 쓰고 있다. gemma4:e4b 는 아직 시험해 보지 않아서 "시험해 볼 것"으로 적어 두었다.

## Ollama 를 쓰는 세 가지 방법

1. 터미널에서 직접 대화: `ollama run 모델이름`
2. 프로그램이 서버 주소로 요청: `http://localhost:11434/api/chat`
3. 라이브러리를 거쳐서: ollama 파이썬 패키지, LangChain

오전 실습 코드는 두 번째 방법을 파이썬 기본 기능 `urllib` 로 썼다.

## Ollama 앱 화면 읽는 법

- **Apps 화면**: Ollama 모델을 연결해 쓰는 다른 프로그램 목록이다. 실습에는 필요 없다. 다만 앱이 켜져 있으면 뒤에서 서버도 돌고 있다
- **Chat 화면의 모델 목록**

  | 표시 | 뜻 |
  |---|---|
  | 구름 | Ollama 회사 서버에서 돈다. 인터넷이 필요하고 질문이 밖으로 나간다 |
  | 아래 화살표 | 아직 받지 않았다 |
  | 표시 없음 | 내 컴퓨터에 있다 |

세무 자료처럼 밖으로 나가면 안 되는 내용을 다룰 때는 구름 표시가 있는지 꼭 봐야 한다.

## 프로그램과 패키지

오후 실습 코드(`prompt_lab.py`)는 `from ollama import ...` 를 썼다. Ollama 를 이미 깔아 두었는데도 패키지를 따로 설치해야 했다.

- **Ollama 프로그램**: 모델을 내 컴퓨터에서 돌리는 서버
- **`ollama` 파이썬 패키지**: 파이썬 코드에서 그 서버에 말을 거는 도구

둘은 다른 것이다. 오전 코드는 `urllib` 로 서버 주소에 직접 보내서 패키지가 필요 없었고, 오후 코드는 패키지를 써서 필요했다.

실습 코드는 경로마다 필요한 패키지가 달랐다.

| 경로 | 패키지 |
|---|---|
| Claude | `claude-agent-sdk` (이미 설치돼 있었음) |
| Gemini | `langchain-google-genai` |
| Ollama | `ollama` |

## pip 은 폴더가 아니라 파이썬에 설치된다

- `pip install` 은 지금 있는 폴더가 아니라 **파이썬**에 설치된다. 같은 파이썬이면 어느 폴더에서 설치해도 다 쓴다 (가상환경이 켜져 있으면 그 안에만)
- 설치하기 전에 있는지 먼저 본다

  ```powershell
  pip show claude-agent-sdk langchain-google-genai ollama
  ```

- 이미 있으면 설치해도 `Requirement already satisfied` 가 나오고 아무것도 바뀌지 않는다
- 필요한 패키지 세 개는 실습 자료에 처음부터 다 나와 있었다. 코드를 받을 때 한 번에 확인했으면 하나씩 따로 설치할 일이 없었다

VS Code 문제 창에 `Import "ollama" could not be resolved` 가 노란 세모로 떴다. 오류가 아니라 경고다. 그 줄은 Ollama 경로로 실행할 때만 읽힌다.

## 남길 것

- 코드를 받으면 필요한 패키지를 먼저 한 번에 확인한다 (`pip show`)
- 프로그램을 깔았다고 그 프로그램의 파이썬 패키지까지 깔린 것은 아니다
- 모델 목록의 구름 표시는 질문이 내 컴퓨터 밖으로 나간다는 뜻이다
