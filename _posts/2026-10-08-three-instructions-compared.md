> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 과업

주문 정보 없이 받은 고객 문의 "배송일은 언제인가요?"에 보낼 답변 초안을 쓰게 했다(`prompt_lab.py`).

## 지시 세 가지

| 안 | 지시 |
|---|---|
| A (최소) | "고객 문의에 답변 초안을 작성하라." |
| B | A + 정중한 한국어 / 입력에 없는 배송일·주문 상태·운송장 번호를 추정하거나 단정하지 말 것 / 정보가 부족하면 한 가지만 요청 |
| C | B + `reply`, `question` 두 키를 가진 JSON 객체만 출력 |

보낸 곳은 세 군데다.

- Claude Haiku 4.5
- Gemini 3.7 Flash
- Ollama qwen3.5:2b (temperature 0, 생각 끔)

안마다 3번씩 보냈다. 실행 오류가 난 것은 내용 채점에서 뺐다.

## 채점 기준은 실행 전에 정했다

결과를 보고 기준을 정하면 결과에 맞춰 기준을 고르게 된다. 그래서 먼저 정했다. 모두 통과/실패로 본다.

1. 근거 없는 날짜를 말하지 않는다
2. 확정할 수 없다고 밝히고 한 가지를 요청한다
3. 정중한 존댓말
4. (C 안만) JSON 형식

## 결과 (통과 / 채점 횟수)

| 모델 | 안 | 날짜 금지 | 한 가지 요청 | 문체 | 형식 | 원문 근거 |
|---|---|---|---|---|---|---|
| Claude | A | 2/3 | 0/3 | 3/3 | - | "표준 배송: 주문 후 2-3일 소요" |
| Claude | B | 3/3 | 3/3 | 3/3 | - | "주문 번호를 알려주실 수 있을까요?" |
| Claude | C | 3/3 | 3/3 | 3/3 | **0/3** | 세 번 모두 ```` ```json ```` 표시 |
| Gemini | A | 0/3 | 0/3 | 3/3 | - | "영업일 기준 [2~3일] 정도 소요", 여러 정보 요청 |
| Gemini | B | 3/3 | 3/3 | 3/3 | - | "주문번호를 알려주실 수 있으실까요?" |
| Gemini | C | 3/3 | 3/3 | 3/3 | 2/3 | 한 번 코드 표시 |
| qwen | A | 0/3 | 0/3 | 3/3 | - | "주문 후 3~5일 이내에 발송", 가짜 링크 |
| qwen | B | 3/3 | **0/3** | 3/3 | - | 주문 상태·운송장 번호 두 가지 (고객이 모르는 정보) |
| qwen | C | 3/3 | **0/3** | 3/3 | 3/3 | "상세 정보나 최근 업데이트된 배송 일정이 있으신가요?" |

- qwen 은 temperature 0 이라 안마다 세 번의 답이 글자까지 같았다
- A 안은 지시가 너무 짧아서, Claude 가 고객에게 답하는 대신 "답변 쓰는 사람"에게 되묻기도 했다

### 한 줄로

- **A → B**: "단정 금지, 부족하면 한 가지 요청"을 넣자 세 모델 모두 날짜를 지어내지 않았다. 한 가지만 묻기는 Claude 와 Gemini 만 지켰고, qwen 은 세 번 모두 두 가지를 물었다
- **B → C**: 형식을 더해도 내용은 B 와 같았다. 형식은 Claude 0/3, Gemini 2/3, qwen 3/3

## 실패한 안만 최소한으로 고쳐 다시 돌렸다

한 번에 여러 문장을 바꾸면 무엇 때문에 나아졌는지 말할 수 없다. 그래서 문장 하나만 덧붙였다(`fix_run.py`).

| 모델 | 안 | 덧붙인 문장 | 전 → 후 |
|---|---|---|---|
| Claude | C → C2 | "코드 블록 표시(`` ``` ``)로 감싸지 말고 JSON 객체만 출력하라." | 형식 0/3 → 3/3 |
| Gemini | C → C2 | 같은 문장 | 형식 2/3 → 3/3 |
| qwen | B·C → B2·C2 | "요청하는 정보는 고객이 알고 있어 답할 수 있는 것 한 가지로 한정하라." | 한 가지 요청 0/6 → 6/6 |

숫자로는 다 고쳐졌다. 그런데 qwen 의 답을 읽어 보니 **"한 가지"는 지켰지만 고른 정보가 쓸모없었다.** B2 는 "상품이나 서비스의 종류"를 물었고, C2 는 여전히 "운송장 번호"를 물었다. 고객이 운송장 번호를 알 리 없다. 규칙의 글자는 지키고 뜻은 놓친 것이다. 채점 기준이 "한 가지인가"만 봤기 때문에 통과로 나왔다.

다시 돌린 결과는 안 이름을 B2·C2 로 붙여서 새 이름으로 저장되게 했다. 처음 결과를 덮어쓰지 않으려고.

## 결론

1. 지시가 짧으면 세 모델 모두 그럴듯한 배송 기간을 지어낸다
2. 같은 지시라도 모델마다 지키는 정도가 다르다. 모델을 바꾸면 다시 채점해야 한다
3. 형식과 내용은 따로 본다. Claude C 는 내용만, qwen C 는 형식만 맞았다
4. 지시는 실수를 **줄이는** 장치이지 **막는** 장치가 아니다. 오전 실습의 qwen 도 "AI 라는 말 금지"를 세 번 다 어겼다
5. 숫자로 통과해도 답을 직접 읽는다. 채점 기준이 묻지 않은 것은 통과로 나온다
