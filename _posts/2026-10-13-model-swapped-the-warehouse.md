> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

도구 설계 5번 노드 실습 2의 두 번째 단계다. 재고 도구에 **없는 창고**를 물어봤다.

## 노드가 말한 것과 실제

질문을 "부산 3번 창고의 A-17 재고를 알려 줘"로 바꿨다. 허락된 창고는 `SEOUL-01`, `BUSAN-02` 둘뿐이다.

- **노드 설명**: 없는 창고로 도구가 불리면 프로그램이 `{"error": "WAREHOUSE_NOT_ALLOWED"}`를 돌려준다. 그 뒤 AI가 창고를 다시 묻는지 본다.
- **실제**:

```
[1] 모델의 요청: [('get_inventory', {'sku': 'A-17', 'warehouse_id': 'BUSAN-02'})]
[2] 하네스의 실행 결과: {"sku": "A-17", "warehouse_id": "BUSAN-02", "available_quantity": 7, "checked_at": "2026-08-27T01:55:00+09:00"}
[3] 결과를 읽은 최종 답: 승인된 창고 (BUSAN-02) 에서 상품 A-17 의 현재 가용 재고는 **7**개입니다.
```

AI가 묻지 않고 "부산 3번"을 `BUSAN-02`(부산 2번)로 바꿔 넣었다. 허락된 창고라서 오류가 안 났고, 내가 묻지도 않은 부산 2번 재고를 답했다.

노드를 다시 보니, 이 질문의 실제 실행 결과 화면은 노드에도 없다. "없는 창고로 호출되면"이라는 조건 문장만 있다.

## 한 곳씩 고쳐 보기

노드는 설명 글 / 허용 목록 / 실패 뒤 행동 중 **한 곳만** 고쳐 다시 돌리라고 한다.
두 곳을 같이 바꾸면 무엇 때문에 달라졌는지 알 수 없어서, 다음 것을 고칠 때 앞에서 고친 것은 되돌렸다.

| 기록 | 고친 곳 | AI가 넣은 창고 | 창고를 다시 물었나 |
|---|---|---|---|
| trace-02 | 설명 글 끝에 "허용되지 않은 창고를 물으면 비슷한 창고로 바꾸지 말고, 허용된 창고 코드를 물어야 합니다." | BUSAN-02 | 안 물음 |
| trace-03 | 창고 칸을 `Literal["SEOUL-01", "BUSAN-02"]`로 바꿔 두 값만 넣게 막음 | BUSAN-02 | 안 물음 |
| trace-04 | 설명 글 끝에 "WAREHOUSE_NOT_ALLOWED이면 허용된 창고 코드를 물어봅니다." (노드 예시) | BUSAN-02 | 안 물음 |

세 곳 모두 행동이 안 바뀌었다. 달라진 건 마지막 답의 말투뿐이었다.

- trace-03: 창고 칸을 두 개로 막았더니, AI는 그 두 개 중 BUSAN-02를 골라 넣었다.
- trace-04: 이 문장은 오류가 나야 쓰이는데, 오류가 안 나니 쓰일 일이 없었다. 그래도 세 곳을 다 고쳐 본 기록을 남기려고 돌렸다.

## 오류 부분이 고장 난 건 아닌가

오류가 한 번도 안 나니까 이상했다. 그래서 AI를 빼고 도구에 `"BUSAN-03"`을 직접 넣어 봤다.

```
1. 원래 도구 → {"error": "WAREHOUSE_NOT_ALLOWED"}
2. 고친 도구 → 막힘: ValidationError 1 validation error for get_inventory_enum
```

- 오류를 내는 부분은 제대로 동작한다.
- 프로그램은 AI가 넘긴 값만 보고 오류를 낼지 정한다. 내가 원래 "부산 3번"이라고 물었다는 건 프로그램이 모른다. AI가 중간에 BUSAN-02로 바꿔 넘겨서 오류가 날 기회가 없었던 것이다.
- 창고 칸을 두 값으로 막아 두면, 함수 안의 오류 검사보다 앞에서 `ValidationError`로 막힌다.

## 배운 것

- 작은 AI(qwen3.5:2b, 온도 0)는 설명 글이나 칸 규칙을 고쳐도, 내가 말한 값을 비슷한 허락된 값으로 바꿔 넣었다. 설명서 한 곳만 고쳐서는 이 실수를 막지 못했다.
- 노드의 "이렇게 될 것이다"는 직접 돌려 봐야 안다.

## 앱과 연결

내 앱(종합소득세 신고 앱)에서 사용자가 없는 세법 항목이나 계정과목을 물으면, AI가 비슷한 항목으로 바꿔 답할 수 있다.
"없는 항목을 물었을 때 비슷한 항목으로 바꾸지 않는가"를 시험 문항에 넣어야 한다.
