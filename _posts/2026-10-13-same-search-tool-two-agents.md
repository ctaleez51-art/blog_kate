> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

도구 설계 5번 노드 실습 2의 마지막 부분이다. 이번에는 도구를 내가 만들지 않고, **남이 만든 프로그램**을 붙였다.

## 왜 하는가

노드에 이런 문장이 있다.

> 에이전트 입장에서는 빌트인 도구이든 MCP로 붙은 도구이든 모델에게 주입되는 도구 정의라는 점이 같습니다.

- 앞 실습의 재고 도구는 내가 코드로 직접 만들었다. AI는 그 함수의 설명 글을 읽고 요청했다.
- 이번 검색 도구는 남이 만든 프로그램을 설정 파일 한 줄로 붙였다.
- 그래도 AI에게는 똑같이 "도구 이름 + 설명 글"로 들어가고, AI는 똑같이 골라 쓰는지 본다.

## 붙인 것

Qdrant는 문장을 저장해 두었다가 비슷한 문장을 찾아 주는 프로그램이다. `mcp-server-qdrant`가 이걸 도구 두 개로 내놓는다.

- `qdrant-store`: 문장 저장
- `qdrant-find`: 비슷한 문장 찾기

## 설정 파일

AI 프로그램에게 "이 폴더에서 켜지면 이 검색 프로그램도 같이 켜서 써라"라고 알려 주는 메모다. 사람이 직접 쓴다.

- Claude Code는 그 폴더의 `.mcp.json`을, opencode는 `opencode.json`을 읽는다.
- 적힌 것은 두 가지다. 어떤 프로그램을 켤지(`uvx --python 3.13 mcp-server-qdrant`), 그 프로그램에 줄 설정값(저장 장소 `:memory:`, 저장 칸 이름 `policies`, 문장 뜻을 읽는 부분 `BAAI/bge-small-en-v1.5`).
- 두 파일은 칸 이름만 다르고(`mcpServers`/`mcp`, `env`/`environment`) 내용은 같다.
- 검색 프로그램은 따로 설치하지 않는다. AI 프로그램이 켜지면서 설정 파일의 `uvx ...`를 실행하고, 그때 uv가 내려받아 켠다. 처음 한 번만 내려받는다.

## 같은 부탁을 두 곳에

| 부탁 | Claude Code (Opus 5.5) | opencode (GPT-6 Sol Fast default) |
|---|---|---|
| 세 문장 저장해 줘 (반품 7일 / 교환 같은 상품 / 환불 원래 결제 수단) | 저장해도 되는지 먼저 묻고, 허락하니 저장 도구로 한 문장씩 3번 | 묻지 않고 저장 도구로 한 문장씩 3번 |
| 반품 기간이 어떻게 돼? | 찾기 도구 없이 기억으로 답함. "직접 찾아본 것은 아니다"라고 밝히고, 저장한 곳에서 찾아볼지 물음 | 찾기 도구 없이 기억으로 답함 |
| 저장한 곳에서 찾기 | 찾아볼지 물은 것에 허락 → 찾기 도구 씀 | "저장한 곳에서 찾아서 확인해 줘" → 찾기 도구 씀 |
| 찾은 결과 | 순서를 보여 줌: 교환, 환불, "반품은 구매 후 7일 안에 할 수 있다."(세 번째) | "반품은 구매 후 7일 안에 할 수 있다."를 확인했다고만 답함. 순서는 안 보여 줌 |

- 두 AI는 같은 도구를 받아서, 같은 부탁에 같은 도구를 골라 썼다.
- 둘 다 방금 저장한 내용은 기억하고 있어서, 저장한 곳에서 찾으라고 해야 찾기 도구를 썼다.
- 다른 것은 찾은 결과를 보여 주는 방식뿐이다. opencode는 순서를 보여 주지 않아서, 두 쪽 검색 결과가 같았는지는 알 수 없다.
- Claude Code가 실제로 넣은 검색어는 화면에 없다. "반품 기간으로 찾겠다"고 말한 것과 실제로 넣은 값은 따로 봐야 한다.
- 이 실습 폴더는 내 작업 폴더 안에 있어서, Claude Code가 내 규칙 파일(`CLAUDE.md`)을 읽고 도구를 쓰기 전에 허락을 물었다. opencode는 묻지 않았다.

## 검색 프로그램은 답을 주지 않는다

Claude Code 결과에서 "반품 기간"을 찾았는데 "반품은 구매 후 7일 안에 할 수 있다."가 세 문장 중 맨 아래로 나왔다.
"반품"이라는 단어가 없는 교환·환불 문장이 더 위에 있었다.

- 찾기 도구는 저장된 문장마다 질문과 얼마나 비슷한지 점수를 매기고, 점수 높은 순서대로 정해진 개수만큼 돌려준다. "맞다/아니다"를 가리지 않는다.
- 이번에는 저장된 게 세 문장뿐이라 세 개가 다 넘어갔고, 답은 그걸 받은 AI가 읽고 만들었다.
- Claude Code는 맨 아래로 나온 이유를 "문장 뜻을 읽는 부분이 영어용(`bge-small-en`)이라 한국어를 잘 구분 못 한 것 같다"고 짐작했다. 한국어용으로 바꿔 다시 해 보지는 않았으니 확인된 것은 아니다.
- 노드가 비교하라고 한 것은 순서가 아니라 두 가지다. 두 AI가 같은 도구를 받았나, 같은 부탁에 같은 도구를 골라 같은 값을 넣었나.

## 앱과 연결

- 세법 문장이 수백 개면, 검색이 돌려주는 몇 개 안에 맞는 문장이 안 들어갈 수 있다. 그러면 AI는 그 문장을 못 보고 답한다.
- 한국어 세법 문장을 찾게 하려면 한국어를 읽는 설정과, 꺼도 지워지지 않는 저장 장소가 필요해 보인다(`:memory:`는 끄면 사라진다). 비교 실험은 아직 안 했다.
