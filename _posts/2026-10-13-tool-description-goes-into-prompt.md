> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

도구 설계 2번 노드의 "실측 랩"을 돌렸다. 확인하려는 것은 하나다.
**AI에게 도구를 쓰라고 시키면, AI는 내 명령 한 줄만 읽는가, 도구 설명도 같이 읽는가.**

- 모델: qwen3.5:2b (Ollama), 온도 0, 생각 모드 끔
- 도구: colab-mcp의 코랩 연결 도구 `open_colab_browser_connection`

## 코드 세 개가 각각 확인하는 것

| 코드 | 한 일 | 결과 |
|---|---|---|
| 1 | AI에게 "구글 코랩을 브라우저로 연결해 줘"를 보내고, AI가 읽은 토큰 수를 봄 | 도구를 골랐고, 읽은 양 289 |
| 2 | 모델 파일에서 채팅 템플릿을 꺼내, AI가 읽었을 입력 글을 직접 만들어 출력 | 위에 도구 설명, 아래에 내 질문 |
| 3 | 코드 2의 글을 그대로 AI에게 보내 토큰 수를 잼 | 288 |

결과는 노드와 같았다.

```
tool_calls: [('open_colab_browser_connection', {})]
prompt_eval_count: 289
```

```
raw prompt_eval_count: 288
```

### 왜 코드가 세 개나 필요한가

- **코드 1**만으로는 AI가 무슨 글을 읽었는지 안 보인다. 289라는 숫자만 나온다.
- **코드 2**로 그 글을 직접 만들어 본다. 맨 위 `system` 칸의 `<tools>` 안에 도구 설명이 들어 있고, 그 아래 `user` 칸에 "구글 코랩을 브라우저로 연결해 줘"가 있다.
- **코드 3**으로 그 글의 양을 잰다. 288로 코드 1의 289와 거의 같다. 그러니 코드 2의 글이 코드 1에서 AI가 실제로 읽은 글이다.
- 1 차이는 시작 표시 처리 방식 차이라고 노드에 적혀 있다.

## 세 코드를 한 파일에 이어 붙인 근거

노드에는 코드 1만 `show_injection.py`로 저장해 실행하라고 적혀 있고, 코드 2·3은 파일 이름이 없다.
그래서 따로 돌려야 하나 헷갈렸는데, 노드를 다시 읽고 두 가지를 확인했다.

1. 코드 2는 코드 1이 만든 `tools`를 쓰고, 코드 3은 코드 2가 만든 `rendered`를 쓴다. 혼자서는 안 돈다.
2. 노드의 실행 명령은 **하나뿐**인데, 거기 세 코드의 패키지가 다 들어 있다.

```
uv run --with langchain-mcp-adapters --with langchain-ollama --with gguf --with jinja2 --with ollama python 파일명
```

`gguf`와 `jinja2`는 코드 2에서만, `ollama`는 코드 3에서만 쓴다. 명령 하나로 세 코드를 돌리라는 뜻이다.
그래서 코드 1 안에 코드 2·3을 이어 붙였다. 노드 코드에서 바꾼 것은 colab-mcp 경로 하나뿐이다.

## 배운 것

- 내가 보낸 것은 한 줄이어도, AI가 받는 글에는 도구 설명이 붙어 있다.
- 그러니 도구 설명을 쓰는 일은 곧 AI에게 주는 지시를 쓰는 일이다.
