> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 과제 조건

세법 뉴스레터 과제의 첫 단계는 자료 수집이다. 소스는 3곳 이상이어야 하고, 교안 실습에서 쓴 소스 6곳(AI 뉴스 사이트들)은 쓸 수 없다. **채택·탈락 이유와 기준**도 밝혀야 한다.

## 기준은 측정 전에 정했다

후보는 6곳이었다. 국세청 보도자료, 국세청 공지사항, 홈택스 공지사항, 국세법령정보시스템의 판례·결정례와 최신개정법령, 기획재정부 세제실.

먼저 판정 기준을 정하고, 그다음에 측정했다. 결과를 보고 기준을 맞추면 기준이 의미가 없기 때문이다.

1. 목록 요청 응답이 200일 것
2. 본문 확보: 최신 10건 중 `정상` 라벨이 1건 이상일 것

측정 코드(`measure_sources.py`)는 소스마다 실제 요청을 만들어 최신 글 10건씩 받았다. 그리고 글마다 본문 상태 라벨을 붙였다.

| 라벨 | 뜻 |
| --- | --- |
| 정상 | 본문 칸을 찾았고 글자가 있음 |
| 이미지·첨부만 | 본문 칸은 있지만 글자가 30자 미만이고 이미지나 첨부만 있음 |
| 빈 본문 | 글자도 이미지도 없음 |
| 잘림 | 본문 칸이나 본문 요청을 못 찾음(수집 실패) |

## 결과: 5곳 채택, 1곳 탈락

| 소스 | 응답 | 본문 상태(10건) | 판정 |
| --- | --- | --- | --- |
| 국세청 보도자료 | 200 | 정상 10 | 채택 |
| 국세청 공지사항 | 200 | 정상 10 | 채택 |
| 홈택스 공지사항 | 200 | 정상 3 · 이미지·첨부만 7 | 채택 |
| 국세법령정보시스템 판례·결정례 | 200 | 정상 10 | 채택 |
| 국세법령정보시스템 최신개정법령 | 200 | 정상 10 | 채택 |
| 기획재정부 세제실 | 200 | 이미지·첨부만 10 | **탈락** |

**기획재정부 세제실은 목록이 잘 열렸다.** 응답도 200이었다. 그런데 글을 열어 보면 웹 본문 칸에는 에디터 스크립트만 있고, 실제 내용은 첨부파일(hwpx·pdf)에만 있었다. 10건 모두 그랬다. 목록만 보고 골랐다면 채택했을 소스다.

**홈택스는 10건 중 7건이 이미지뿐**이었지만, 정상 글이 3건 있어서 기준을 통과했다. 이미지뿐인 글은 요약하지 않고 목록에만 싣기로 했다.

## 쓰지 않은 기준 두 가지

**교안의 본문 길이 기준(600자)은 쓰지 않았다.** 교안의 600자는 RSS 요약만 받았는지, 본문 추출이 잘렸는지 가리는 값이다. 세법 공지는 원래 짧은 글이 많다. 국세청 공지사항에는 71자짜리 글도 있었고, 짧아도 중요할 수 있다. 그래서 잘렸는지는 길이가 아니라 "본문 칸을 찾았는지"로 판단했다(`잘림` 라벨). 30자는 길이로 거르는 값이 아니라 "글자가 없다"를 가리는 값이다.

**최근 게시 여부도 기준으로 쓰지 않았다.** 기관 게시판은 며칠씩 글이 없는 날이 있다. 최근성으로 거르면 멀쩡한 소스가 떨어진다. 최신 글 날짜는 측정 데이터로만 남겼다.

## 해외 서버에서 열리는지도 먼저 봤다

뉴스레터는 GitHub Actions 서버에서 매일 돌 예정이었다. 그 서버는 해외에 있고, 정부 사이트는 해외 접속을 막기도 한다. 그래서 GitHub 서버에서 소스 사이트에 접속만 해 보는 워크플로(`access-test.yml`)를 먼저 돌렸다. 4개 사이트 모두 200이었다.

## 요청 방법을 찾아야 했던 곳

| 소스 | 방식 |
| --- | --- |
| 국세청 보도자료·공지사항 | 목록 화면 HTML을 받아 글 번호·제목·날짜를 뽑고, 상세 화면에서 본문 칸을 잘라 냄 |
| 홈택스 공지사항 | 화면이 부르는 JSON 요청. 본문이 목록과 함께 옴 |
| 국세법령정보시스템 | 공개된 요청 방법이 없어, 화면 HTML과 사이트 스크립트에서 요청 형식을 찾아냄 |

## 남길 것

- 소스는 목록이 열리는지가 아니라 **본문까지 실제로 받아 보고** 고른다.
- 판정 기준은 측정 전에 정한다.
- 교안의 숫자 기준은 그 숫자가 무엇을 가리려고 만든 값인지 보고, 내 분야에 맞을 때만 쓴다.

## 앱과 연결

세무 앱에서 국세청·홈택스 공지를 받아 올 때도, 홈택스와 기획재정부처럼 내용이 이미지·첨부에만 있는 글이 많다. 앱에서 이런 글까지 요약하려면 첨부(hwp·pdf)나 이미지에서 글자를 뽑는 단계가 필요하다.
