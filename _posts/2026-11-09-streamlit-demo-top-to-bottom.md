> 모두의연구소 AI 에이전트 과정 학습 기록입니다.
> Claude와의 대화 내용을 Claude가 초안으로 정리하고, 제가 검토·수정했습니다.
{: .prompt-info }

## 처음 실행할 때 나오는 질문

데모는 `streamlit run app.py` 로 연다. 처음 실행하면 터미널에 이메일을 묻는 안내가 나온다. 비워 두고 Enter 를 누르면 브라우저가 열린다.

## 처음 화면 — 글씨가 작고 오른쪽이 비었다

처음 연 화면은 글씨가 작고 오른쪽이 비어 보였다. 원인은 세 가지였다.

| 원인 | 하는 일 |
|---|---|
| `layout="wide"` | 화면을 브라우저 전체 너비로 펼침 |
| 좌우 2칸 배치 | 내용이 한쪽에 몰리면 다른 쪽이 빔 |
| `st.caption` | 작은 회색 글씨 |

## 고친 것

- 기본 너비(`layout="centered"`)로 바꿨다.
- 2칸을 없앴다.
- 위에서 아래로 이 순서로 보이게 했다.

1. 판정
2. 부른 도구
3. 답변
4. 검증 결과
5. 근거

에이전트가 처리하는 순서 그대로다. 화면을 위에서 아래로 읽으면 처리 과정을 따라가게 된다.

## 검증 결과를 화면에서 바로 대조

검증 결과 칸에는 답변 속 숫자와 붙인 근거 번호를 그대로 보여 준다.

둘째 출산 질문 화면에서 답변에 나온 0·8·50 이 모두 근거 QA-102 에 있는 숫자인지 바로 대조할 수 있었다. 코드가 검사한 것을 화면에서 사람이 한 번 더 확인할 수 있게 된 것이다.

## 캡처 두 장

화면이 길어서 캡처를 두 장으로 나눴다.

- 1.png 위쪽 — 판정, 부른 도구
- 2.png 아래쪽 — 답변, 검증, 근거

둘 다 REPORT.md 6절(데모 설계)에 넣었다.

## 정리

- 나는 데모 화면을 처리 순서대로 위에서 아래로 배치한다.
- 넓은 화면 설정과 칸 나누기는 내용이 적으면 빈 곳만 만든다.
- 검증에 쓴 값(숫자, 근거 번호)은 화면에 그대로 보여 준다.

## 앱과 연결

- 신고 앱의 상담 화면에도 판정 카테고리, 근거 번호, 근거 원문을 같이 보여 준다. 그러면 답이 어디서 왔는지 사용자가 직접 대조할 수 있다.
